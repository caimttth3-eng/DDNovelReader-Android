## 功能概览

### 书架
- 4 列木纹卡片展示书籍，底部腰封显示阅读进度
- 首位固定「添加书籍」占位卡，点击调用系统文件管理器选书
- 支持 TXT / EPUB 格式导入，无限下滑滚动

### 阅读
- 全屏三区点击：上区上翻页、中区显隐 UI、下区下翻页
- 顶部栏：返回 / 播放 / 设置（亮度、字体大小、行距、查找）
- 左侧悬浮球：章节目录，打开时自动定位到当前阅读章节
- 底部进度条：滑动跳转 + 百分比显示
- 自动保存阅读进度，意外退出不丢失

### 朗读模式
- 点击播放按钮进入：全屏无 UI，TTS 开始朗读，高亮逐句跟随滚动
- 点击屏幕暂停，底部弹出控制面板：
  - 语速调节（0.5x – 2.0x，滑块 + 加减按钮）
  - 定时播放（15 / 30 / 60 / 90 分钟）
  - 切换音源（6 个中文音色）
  - 退出朗读（电源按钮，恢复正常阅读 UI）
- 上下滑动：字符级快进/快退（每像素 2 字，句子级精度）
- 音量键：逐句跳转（朗读模式下生效）
- 耳机播放键：控制播放/暂停（MediaSession）

### 文本处理
- 双文本底层：显示保留原文标点/空白，TTS 朗读使用纯净文本（去除连续标点、空白、emoji）
- 智能分章：识别「第 X 章 / 第 X 卷 / Chapter N / 序章 / 楔子 / 番外」等标题，适配百万字级小说
- 句子级切分，高亮精确到句子

## 技术说明
- Edge TTS 在线合成（微软 Edge 朗读协议），无需系统 TTS 引擎
- 6 个中文音色：晓晓（女温暖）、云希（男阳光）、云扬（男专业）、晓伊（女活泼）、东北小北、陕西小妮
- 句子级 item 架构，高亮精确跟随滚动
- audio_service MediaSession 耳机联动

## 与 PC 版区分
- 本目录 `releases/android/` 为安卓版发布产物
- PC 版（Python 桌面版）为独立项目，不在本仓库
- 安卓版包名 `com.duoduo.duoduo_langdu`，应用名「多多朗读」
