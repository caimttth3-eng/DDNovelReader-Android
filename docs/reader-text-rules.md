# 阅读正文处理

设置默认：点击左右侧翻页（仅点击生效）、字号 20（上限 64）、文本修正开启、首行缩进开启、无关信息过滤关闭。

点击和左右滑动采用完整文本行分页，页底放不下的整行留到下一页，不显示上下半行。“翻页后保留首行”默认关闭；开启后将上一页最后一整行作为下一页首行，仅对两种翻页方式有效，上下滚动时禁用。

正文与朗读使用同一份处理结果，原始导入文件不改写。关闭开关后从原始文本重建；处理结果不会覆盖源文件。

## 文本修正

- 统一 CRLF/CR/LF 换行。
- 非句末的物理断行合并；句末包括句号、问号、叹号、分号、省略号和英文句点，允许尾随闭引号、右括号。章节之间不合并。
- 英文字母/数字之间的断行保留一个词间空格。
- 当上一行存在未配对左双引号，且下一行以右双引号开头时，将该闭引号归到上一行末尾。不补写缺失引号，不反转原文引号方向。
- 句末闭引号属于前一句；段落内多个句子连续排版，避免按句子单独成段。
- 清理 BOM、零宽字符、软连字符等不可见字符。

首行缩进是独立开关：段首不足两个空格时改为两个全角空格；已有两个及以上空格时保留。正文按段落两端对齐。

排版允许标点位于行首：仅在显示层加入零宽断行机会，避免标点禁则把前面的汉字一起推到下一行而拉大字距。保存进度、书签、划线和朗读高亮时映射回原文坐标，不删除行尾字符。

## 朗读高亮

整句使用浅色底，正在读的词使用更醒目的蓝色底和深色文字。词的位置来自 Edge `WordBoundary` 元数据，时间来自播放器实际进度，暂停后高亮保持，继续播放按实际进度更新。音频和词时间戳一起缓存，缓存播放也使用相同时间轴。音源没有返回有效词时间戳时保留句子高亮，不生成估算的逐词进度。

音源增加“使用系统文本转语音能力”，调用 Android 设置中的默认引擎和音色；能否离线取决于引擎及已安装语音包。系统引擎提供范围回调时更新词高亮，否则保留句子高亮。系统语音与在线语音缓存分开；选择系统语音时不请求 Edge 合成。

加载状态跟随实际连接、合成及播放器启动结果。取消与切句会废弃迟到回调；失败停在当前句，不以“自动跳过三句”掩盖失败。在线服务拒绝、连接/合成超时、系统引擎未配置和播放失败使用不同提示，移除原先固定五秒的网络超时提示。CI 的可选真实合成探测对比固定的 v1.2.6 传输代码与当前实现；服务探测失败不冒充单元测试失败，也不隐瞒其结果。

语速统一为 0.5–3.0 倍，保存上次设置，变速后更新对应缓存参数；音量与语速滑条同长，语速滑条和加减按钮在同一行。亮度和字号滑条也同长；亮度的系统重置按钮用灯泡内的 A 表示。

播放设置栏打开且应用在前台时，音量滑条持续读取系统媒体音量；音量键调整后也会同步。隐藏面板或进入后台时停止读取，拖动/写入期间用版本号防止旧读数回滚用户操作。

在线队列先准备当前句，再预取后续句；预取任务与内容版本绑定，旧章、旧语速的迟到结果不会写入新队列。停止或跳句期间的旧播放完成事件被忽略。系统语音随共享 FlutterEngine 管理生命周期，避免 Activity 重建时误停后台语音。

## 无关信息过滤

默认关闭。开启后展开级别，首次不自动选级别；选定后才执行过滤。关闭后恢复未过滤内容。

1. 一级：网址与邮箱。
2. 二级：一级加明确广告行，如“访问本站”“记住本站”“本书来自”“下载 APP”“加入 QQ 群”等，按整行规则匹配。
3. 三级：二级加求票、求收藏、作者说明、PS、未完待续等行。

规则避免将普通叙事中出现的“网址”等词当成广告。关闭过滤即可查看原文；三级适合明确希望隐藏作者附言的用户。

## 位置与语音缓存

每本书单独保存章节、正文位置和视口偏移。在相同排版下恢复到原屏幕位置；排版规则改变后，通过源文本字符坐标恢复到对应正文。书签和划线也使用源文本坐标映射。

切换修正/过滤时捕获当前首行的原文坐标及屏幕高度，恢复该行的排版起点与位置；显示层的续行锚点随进度保存。如果锚点文字本身被过滤，则定位到其后的保留正文。菜单书签按钮添加当前阅读位置；查看书签仍在左侧目录面板。

语音缓存目录保留按书籍管理，在音色/语速目录内再按整书分句内容指纹隔离。修正或过滤改变 TTS 文本后，不使用旧坐标下可能错误的音频；关闭规则后可重新使用对应指纹的缓存。

## 参考

- [calibre：启发式处理](https://manual.calibre-ebook.com/conversion.html#heuristic-processing)：依据标点和排版线索修复硬断行。本项目按用户要求采用明确句末规则，不自动纠正词语和情节。
- [Legado：替换净化](https://github.com/LegadoTeam/legado)：参考规则化净化及可关闭的设置形式；本项目提供内置分级规则。
- [edge-tts 的词边界协议](https://github.com/rany2/edge-tts/blob/master/src/edge_tts/communicate.py)：读取音频元数据中的词与时间戳。
- [Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)及[进度回调](https://developer.android.com/reference/android/speech/tts/UtteranceProgressListener)：接入系统引擎；范围回调取决于系统版本和引擎支持。
- [scrollable_positioned_list 源码](https://github.com/google/flutter.widgets/blob/master/packages/scrollable_positioned_list/lib/src/scrollable_positioned_list.dart)：按索引定位；页间动画捕获当前画面，不额外建立带负对齐锚点的列表。

自动化覆盖文本与朗读分句、闭引号、原始缩进、分级过滤、源坐标映射、缓存指纹、逐书进度恢复、三种翻页输入以及远距离跳转/滚动后翻页和进入朗读。实际设备上的音频播放与手感仍需实机验证。
