# 阅读正文处理

设置默认：点击左右侧翻页（仅点击生效）、字号 20（上限 64）、文本修正开启、首行缩进开启、无关信息过滤关闭。

正文与朗读使用同一份处理结果，原始导入文件不改写。关闭开关后从原始文本重建；处理结果不会覆盖源文件。

## 文本修正

- 统一 CRLF/CR/LF 换行。
- 非句末的物理断行合并；句末包括句号、问号、叹号、分号、省略号和英文句点，允许尾随闭引号、右括号。章节之间不合并。
- 英文字母/数字之间的断行保留一个词间空格。
- 当上一行存在未配对左双引号，且下一行以右双引号开头时，将该闭引号归到上一行末尾。不补写缺失引号，不反转原文引号方向。
- 句末闭引号属于前一句；段落内多个句子连续排版，避免按句子单独成段。
- 清理 BOM、零宽字符、软连字符等不可见字符。

首行缩进是独立开关：段首不足两个空格时改为两个全角空格；已有两个及以上空格时保留。正文按段落两端对齐。

## 无关信息过滤

默认关闭。开启后展开级别，首次不自动选级别；选定后才执行过滤。关闭后恢复未过滤内容。

1. 一级：网址与邮箱。
2. 二级：一级加明确广告行，如“访问本站”“记住本站”“本书来自”“下载 APP”“加入 QQ 群”等，按整行规则匹配。
3. 三级：二级加求票、求收藏、作者说明、PS、未完待续等行。

规则避免将普通叙事中出现的“网址”等词当成广告。关闭过滤即可查看原文；三级适合明确希望隐藏作者附言的用户。

## 位置与语音缓存

每本书单独保存章节、正文位置和视口偏移。在相同排版下恢复到原屏幕位置；排版规则改变后，通过源文本字符坐标恢复到对应正文。书签和划线也使用源文本坐标映射。

语音缓存目录保留按书籍管理，在音色/语速目录内再按整书分句内容指纹隔离。修正或过滤改变 TTS 文本后，不使用旧坐标下可能错误的音频；关闭规则后可重新使用对应指纹的缓存。

## 参考

- [calibre：启发式处理](https://manual.calibre-ebook.com/conversion.html#heuristic-processing)：依据标点和排版线索修复硬断行。本项目按用户要求采用明确句末规则，不自动纠正词语和情节。
- [Legado：替换净化](https://github.com/LegadoTeam/legado)：参考规则化净化及可关闭的设置形式；本项目提供内置分级规则。
- [scrollable_positioned_list 源码](https://github.com/google/flutter.widgets/blob/master/packages/scrollable_positioned_list/lib/src/scrollable_positioned_list.dart)：按索引定位；页间动画捕获当前画面，不额外建立带负对齐锚点的列表。

自动化覆盖文本与朗读分句、闭引号、原始缩进、分级过滤、源坐标映射、缓存指纹、逐书进度恢复、三种翻页输入以及远距离跳转/滚动后翻页和进入朗读。实际设备上的音频播放与手感仍需实机验证。
