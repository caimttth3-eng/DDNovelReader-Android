# 阅读正文处理

设置默认：普通阅读上下滚动（可改点击或滑动翻页）、字号 20（上限 64）、文本修正开启、首行缩进开启、无关信息过滤开启一级。已保存的翻页选择保留。

点击和左右滑动按实际排版的完整文本行分页。翻页目标和底部裁切使用同一个连续行范围和实际视口高度；混合字体或双向文本产生的多个字框按行合并。缓存行以 Flutter 的滚动位置计算，不用未绘制段落可能被钳制的绘制坐标。恢复进度或重排后若只看到部分行，仍有明确的前后行锚点，不会卡在原页；字号、行高、视口或文字缩放变化时废弃旧页边界。无论翻页方向或是否启用动画，定位期间均遮住新页，待新页的裁切应用后才显示，避免以旧页的裁切范围画出新页半行。

参考 [Flutter 视口定位 API](https://api.flutter.dev/flutter/rendering/RenderAbstractViewport/getOffsetToReveal.html) 和 [Readium 双向翻页的同一坐标基准](https://github.com/readium/kotlin-toolkit/blob/89b96c20c447d0aec17db57a06456b7decffde4c/readium/navigator/src/main/assets/_scripts/src/utils.js#L195-L229)。本项目使用现有段落渲染结果，不另排版一遍，也不维护第二套朗读界面。“翻页后保留首行”默认关闭；开启后将上一页最后一整行作为下一页首行，仅对两种翻页方式有效，上下滚动时禁用。

正文与朗读使用同一份处理结果，原始导入文件不改写。关闭开关后从原始文本重建；处理结果不会覆盖源文件。

## 文本修正

- 统一 CRLF/CR/LF 换行。
- 非句末的物理断行合并；句末包括句号、问号、叹号、分号、省略号和英文句点，允许尾随闭引号、右括号。章节之间不合并。
- 英文字母/数字之间的断行保留一个词间空格。
- 当上一行存在未配对左双引号，且下一行以右双引号开头时，将该闭引号归到上一行末尾。不补写缺失引号，不反转原文引号方向。
- 句末闭引号属于前一句；段落内多个句子连续排版，避免按句子单独成段。
- 清理 BOM、零宽字符、软连字符等不可见字符。

首行缩进是独立开关：段首不足两个空格时改为两个全角空格；已有两个及以上空格时保留。正文按段落两端对齐。

排版允许标点位于行首：仅在显示层加入零宽断行机会，避免标点禁则把前面的汉字一起推到下一行而拉大字距。保存进度、书签、划线和朗读高亮时映射回原文坐标，不删除行尾字符。

## 朗读高亮

前台朗读只整页翻页，不在页内滚动。收到实际朗读位置并越过页界时翻页，页界不再切断语音。音源未报告词位置时，在下一句定位页面，不猜测句内翻页时机。自动朗读翻页不重复上一页末行；“翻页后保留首行”仍用于手动翻页。

手动翻页是显式跳读：系统及在线音源都从目标页首个可读字符开始，而非回到该字符所在句的句首。起读位置直接取已定位的页首行，不再从滚动视口重新猜测；成功翻页后不重放旧音频的定位回调。句子和词高亮在页底止于同一行边界，不给隐藏行绘制语音背景。两条路径共用显示字符与语音字符映射，但自动翻页只改变页面并连续播放，不发送手动跳句命令。跨段、跨章若仍在当前页内，不强行换页；回到前台时当前词仍在本页内也不移动页面。后台不等待 UI 绘制，继续语音，回到前台再按页追到实际进度。

朗读遇到破折号（U+2014 `—` 或 U+2015 `―`）时在符号前后分段，前段音频结束后默认追加 200 毫秒停顿，可在播放设置中调整。连续破折号只停顿一次；屏幕保留原符号，语音不念破折号。不把普通半角连字符、负数或日期中的 `-` 当成破折号。纯破折号与空白不产生空朗读请求；朗读分段保留原文坐标，语音缓存指纹包含停顿配置。

整句使用浅色底，正在读的词使用更醒目的蓝色底和深色文字。词的位置来自 Edge `WordBoundary` 元数据，时间来自播放器实际进度，暂停后高亮保持，继续播放按实际进度更新。音频和词时间戳一起缓存，缓存播放也使用相同时间轴。音源没有返回有效词时间戳时保留句子高亮，不生成估算的逐词进度。

音源提供“系统语音（离线）”默认入口及已安装的具体系统音色。Android 使用系统默认引擎，iOS 使用 AVSpeechSynthesizer；能否离线取决于引擎及已安装语音包。所有系统音色共用现有页首光标、范围映射和追加停顿配置，不单独维护朗读排版。系统引擎提供范围回调时更新词高亮，否则保留句子高亮；选择系统语音时不请求 Edge 合成。

加载状态跟随实际连接、合成及播放器启动结果。取消与切句会废弃迟到回调；失败停在当前句，不以“自动跳过三句”掩盖失败。在线服务拒绝、连接/合成超时、系统引擎未配置和播放失败使用不同提示，移除原先固定五秒的网络超时提示。CI 的可选真实合成探测对比固定的 v1.2.6 传输代码与当前实现；服务探测失败不冒充单元测试失败，也不隐瞒其结果。

音色和语速按书保存，普通打开及准备/快照路径共用设置恢复。语速按 0.02 调整，在线和 iOS 系统上限 2.0 倍、Android 系统上限 3.0 倍，最低均为 0.5；切换时收紧超出新上限的值，变速后更新对应缓存参数。音量与语速滑条同长，语速滑条和加减按钮在同一行。亮度和字号滑条也同长；亮度的系统重置按钮用灯泡内的 A 表示。

播放设置栏打开且应用在前台时，音量滑条持续读取系统媒体音量；音量键调整后也会同步。隐藏面板或进入后台时停止读取，拖动/写入期间用版本号防止旧读数回滚用户操作。

在线队列先准备当前句，再预取后续句及下一章开头最多 3 句；跨章预取复用当前缓存身份、原文坐标和词元数据，不另用一套分句或合成入口。预取任务与内容版本绑定，旧章、旧语速的迟到结果不会写入新队列，断网取消传输。停止或跳句期间的旧播放完成事件被忽略。系统语音随共享 FlutterEngine 管理生命周期，避免 Activity 重建时误停后台语音。系统音频中断恢复沿用现有暂停词位置，手动暂停或改变朗读任务后忽略旧恢复事件。

自动翻页不重新合成或启动播放器，原有标点和段落停顿不变。手动跳读到句中时，可单独合成从目标页首字到句末的音频，不误用整句缓存；暂停和继续沿用当前音频。

## 无关信息过滤

默认开启一级，可关闭或调整级别；关闭后恢复未过滤内容。

1. 一级：网址与邮箱。
2. 二级：一级加明确广告行，如“访问本站”“记住本站”“本书来自”“下载 APP”“加入 QQ 群”等，按整行规则匹配。
3. 三级：二级加求票、求收藏、作者说明、PS、未完待续等行。

规则避免将普通叙事中出现的“网址”等词当成广告。关闭过滤即可查看原文；三级适合明确希望隐藏作者附言的用户。

## 位置与语音缓存

自动提取目录默认开启，目录索引借鉴 [Legado 官方 TXT 规则族](https://github.com/LegadoTeam/legado/blob/master/app/src/main/assets/defaultData/txtTocRule.json)及 calibre 的结构检测思路，自行实现中文/繁体/大写数字、卷章混排、英文 Chapter/Section/Part/Episode、序章和尾声等独立行检测，并限制长度、排除正文句号、网址、课堂/回合等常见误判。普通数字或中文编号标题需要多项隔着正文重复出现；不把任意短行都当标题。此实现不是复制外部规则文件，也不保证识别所有非标准标题。

目录是指向原章节、原段落和字符位置的索引，不重新切割已导入正文，不删除标题或前言，因此切换不会改变进度、书签、划线或朗读队列坐标。关闭提取后按约 5000 个非空白 Unicode 字符建立虚拟分节索引，保留原文位置；单章标题也可识别，未识别到可信标题时使用相同虚拟分节兜底。解析器原有基础分章逻辑保持兼容，新增索引可直接用于已有书籍。

每本书单独保存章节、正文位置和视口偏移。在相同排版下恢复到原屏幕位置；排版规则改变后，通过源文本字符坐标恢复到对应正文。书签和划线也使用源文本坐标映射。

切换修正/过滤时捕获当前首行的原文坐标及屏幕高度，恢复该行的排版起点与位置；显示层的续行锚点随进度保存。如果锚点文字本身被过滤，则定位到其后的保留正文。菜单书签按钮添加当前阅读位置；查看书签仍在左侧目录面板。

语音缓存以跨端 `contentKey` 管理，语速目录为 Edge 整数百分比；显示原始 UTF16 位置经共享映射转换为桌面规范化正文的 Unicode 码点坐标，排版后也沿用该坐标。原始缩进/断行不被解析器不可逆覆盖，进度、整书缓存及朗读共用转换，避免仅目录格式相同但读错音频。

在音色/语速目录内仍按实际分句与停顿内容指纹隔离。`words2` 标识坐标升级，旧 `words1` 或无指纹 TTS 下标音频不直接当作新格式复用。迁移只处理本书，目标内容不同时保留两份，不静默删旧文件；失败会记录诊断。旧缓存可能需要重建，但不会以错误命中换取兼容声明。

## 参考

- [calibre：启发式处理](https://manual.calibre-ebook.com/conversion.html#heuristic-processing)：依据标点和排版线索修复硬断行。本项目按用户要求采用明确句末规则，不自动纠正词语和情节。
- [Legado：替换净化](https://github.com/LegadoTeam/legado)：参考规则化净化及可关闭的设置形式；本项目提供内置分级规则。
- [edge-tts 的词边界协议](https://github.com/rany2/edge-tts/blob/master/src/edge_tts/communicate.py)：读取音频元数据中的词与时间戳。
- [Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)及[进度回调](https://developer.android.com/reference/android/speech/tts/UtteranceProgressListener)：接入系统引擎；范围回调取决于系统版本和引擎支持。
- [scrollable_positioned_list 源码](https://github.com/google/flutter.widgets/blob/master/packages/scrollable_positioned_list/lib/src/scrollable_positioned_list.dart)：按索引定位；页间动画捕获当前画面，不额外建立带负对齐锚点的列表。

自动化覆盖文本与朗读分句、闭引号、原始缩进、分级过滤、源坐标映射、缓存指纹、逐书进度恢复、三种翻页输入以及远距离跳转/滚动后翻页和进入朗读。实际设备上的音频播放与手感仍需实机验证。
