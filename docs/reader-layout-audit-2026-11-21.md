# 过滤、分页与朗读联动设计审查

本轮用户要求按模块、按顺序完整审查，并对照成熟开源阅读器。仅使用合成书籍和公开资料，不读取真实书籍、个人配置或签名资料。本文记录计划、证据和取舍；最终结论以实际复现及验证为准，不将静态疑点写成已确认故障。

## 顺序与分工

| 阶段 | 检查范围 | 执行者 | 验收依据 |
| --- | --- | --- | --- |
| 1 | 原文、三级过滤、合并/缩进、原文锚点与句坐标 | 文本映射子代理 | 重复切换后存活正文的原文坐标、映射单调性及句位置；被删除内容采用明确的前向投影 |
| 2 | 排版行、分页窗口、裁切、捕获/恢复、翻页并发 | 页面子代理与主流程 | 普通/播放/暂停，点击/滑动/滚动，过滤等级往返；实际首行、像素位置、可容纳末行及连续性 |
| 3 | 成熟开源产品的重排定位、页边界和朗读协调 | 资料调研子代理 | 官方源码/官方文档，区分实际实现、借鉴点和不适用之处 |
| 4 | 统一现有机制、修复有证据的问题 | 主流程独占产品改动 | 修复前失败、修复后通过；不新增另一套正文、进度、缓存或分页真相 |
| 5 | 整体回归、本地签名 APK 与收尾 | 主流程独占 Prepare | 完整 Flutter 套件、静态分析、真实 Android 构建、SDK 审计和既有 LocalApk 接收 |

音色及系统语言的选择圆点同时统一到名称前的固定 leading 槽，右侧只保留操作按钮；这是独立 UI 修改，不作为排版问题的修复。

## 应保持的不变量

1. 原书不可变；过滤、缩进和合并只产生带映射的显示投影。书签/进度使用原文锚点，不能保存当前页号代替原文位置。
2. 显示视口锚点与朗读光标分别保存。切设置时，页面保留存活的首行与相对位置，朗读保留真实句/词位置；当前行被过滤时向后投影到存活文本。
3. 起读、手动翻页、自动翻页、页面裁切和重排恢复使用同一行几何与一致的精度规则。不能一处允许残余行距盒，另一处只接受完整行。
4. 格式化结果、行布局、手动换行及页末限制属于对应排版代次。内容或几何变化后，不得沿用旧坐标截掉新页，也不得由旧异步恢复覆盖新导航。
5. 重排是一项可见性事务：捕获锚点与旧页 → 准备新文本 → 安装并恢复 → 重算裁切 → 新帧完成 → 撤下旧页 → 继续朗读。中间跳到段首的工作状态不能暴露给用户。
6. 切换期间的导航及媒体操作必须有明确优先级和代次检查；最新用户意图优先，过期回调不能回滚位置、保存错误进度或重启旧朗读。

## 初步设计疑点（调查起点，验证结果见下文）

- `_play` 在 1.3.14 已使用分页窗口的完整首行，但 `_captureLineAnchor` 仍有独立的 item 边缘与 hit-test 规则。过滤重排可能再次引入不同的首行判定。
- 行对齐及页首允许约 0.25 像素残差，页底容纳判断却近似严格零误差。需要验证亚像素残差是否足以少显示一整行。
- 视口恢复使用自己的 revision；需要检查它与导航 generation、翻页 finally 及待刷新朗读回调的交接是否一致。
- 旧页快照的撤下、页末限制清理及新裁切绘制的顺序需要逐帧验证，不能只检查最终首行。
- 正文视口下方有现有固定页脚空间；测试应以真实正文视口判断“还能放下一行”，不能把页脚预留误判为裁切故障。

## 当前取舍

原文锚点、纯投影格式化和先准备后发布的方向可以保留。优先用复现证据判断行几何、事务顺序和代次交接是否需要统一，不因局部症状直接重写整套阅读器。成熟产品调研、测试结果及最终修改将在下文补齐。

## 方案判断与验证边界

问题集中在视口规则和异步状态交接，而非“三级过滤必须换一种正则算法”。本轮沿用原文锚点和现有渲染器，统一行几何、布局所有权及提交顺序，并让最新用户导航/媒体意图优先；没有另建正文、进度或分页系统。

只对有复现或明确代码证据的路径作修正。被过滤掉的锚点继续向后投影到存活正文，不承诺原行已删除时页面文字仍完全相同；没有扩展裸域名过滤规则。合成测试不能代替真机字体、系统缩放及手势手感验收；本轮未生成截图、读取真实书籍或安装设备。最终完整验证、成品和收尾将以对应版本交付记录为准。

### 大字号页底空白的修复前证据

新增 `test/reader_page_bottom_test.dart`，以 40/64 字号、1.8 倍行高、单长段/多短段构成四个场景。夹具把真实正文视口高度放在同一尾行的字体高度盒与含行距盒之间，页脚已经排除在正文范围之外。修复前四项均在“完整可容纳的尾行被裁掉”断言失败，记录位于实例 `temp/layout1316-bottom-before-valid.log`。

| --- | ---: | ---: |
| 40，单长段 | 623.75 | 560.00 |
| 40，多短段 | 635.75 | 572.00 |
| 64，单长段 | 967.95 | 866.00 |

表内坐标均为合成测试的逻辑像素和全局页面坐标，不是对手机截图像素的反推。其证明的是同类裁切缺陷确实存在，未声称手机使用与宿主测试相同的字体度量。

原实现使用 `BoxHeightStyle.includeLineSpacingMiddle`：它把行间距分别扩展到相邻行的上、下边界。页尾下一行的文字高度已经放得下时，其额外下半行距仍可能越过正文下缘，于是整行被排除。大字号和较大行距放大了这项差异。固定页脚及真实段间距仍占用各自空间，但不是上述四项复现中多裁尾行的原因。

### 采用的几何规则与保留范围

分页测量、可见文字定位和朗读字形可见性统一采用 `BoxHeightStyle.max`。[Flutter 官方枚举说明](https://api.flutter.dev/flutter/dart-ui/BoxHeightStyle.html) 明确区分：`max` 采用该行所有文字片段的最大字体高度，使同行各盒等高；`includeLineSpacingMiddle` 还覆盖额外行距。由此既能按整行字体高度检查页尾，也避免混合字体按各片段紧盒测量时高度不一致。

现有行距、段间距、字号、正文宽度和 32 逻辑像素页脚预留均保留，标点换行策略也保持原样。允许尾行完整文字进入页内时，尾行下方没有必要保留本属于下一行之前的额外行距；页内相邻行的实际距离仍由原排版决定。前后翻页、可选重叠末行、TTS 高亮边界与起读沿用同一行规则，源文本到显示文本的偏移转换不变。布局身份提升至 `typography5`，使旧版按含行距盒保存的像素视口通过已有原文锚点恢复。

新增四项回归还检查：新容纳的末行不会在下一页重复，前进再后退能恢复同一行及其位置。既有测试的完整行测量同步改为新的字体高度盒；新增测试保留含行距盒作为比较证据。修复后这四项已通过，完整终测、APK 和收尾以本轮最终交付记录为准。

整行分页仍可能在页底留下不足下一行实际进距的余量；段落或章节边界也可能留下真实间隔。若要求每页正文底部严格齐平，需要另行分配行距或段距，会改变用户设定的视觉节奏，本次保留原设置。

### 快速过滤与翻页的事务边界及后续方案

本次另以独立门控检查“文本准备完成时翻页未结束”“新列表已安装但恢复未结束”“多个过滤草稿在同一准备期间到达”三个窗口，逐帧检查旧页遮罩和最终位置。产品修正方向是：准备期间保留普通导航，待当前翻页结束后再捕获可见原文锚点；合并较新的设置草稿，过期准备结果不安装、不保存；新布局恢复并完成裁切后再消费期间收到的翻页请求。这部分与大字号几何分别验证，阶段失败及最终结果由主流程的本轮证据补充，不能由四项页底测试替代。

长期可以考虑按每个排版代次生成不可变的页面切片目录，以原文锚点对应首末行，并在过滤重排后整体切换目录。它有利于集中管理页边界，但需要额外维护字体与缩放身份、缩进占位、混合方向排版、分章缓存失效、自由滚动与页面目录的互转，以及 TTS 跨页跟随。本项目现有真实文字测量和原文映射可继续复用，因此本次先完善现有布局事务、导航完成屏障和最新草稿所有权；页尾几何修复无需等待整套分页器迁移。上述取舍是本项目的设计判断，成熟阅读器的对应原则仍见前文官方源码对照。

### 快速操作的实际复现与完成屏障

### 再核成熟实现与页面高度方案

这次重新实际读取官方源码和规范，避免把旧推断循环引用为成熟实现事实：

| 官方主源 | 本次实际核对的机制 | 本项目取舍 |
| --- | --- | --- |
| [KOReader / CREngine `lvpagesplitter.cpp`](https://github.com/koreader/crengine/blob/master/crengine/src/lvpagesplitter.cpp#L784) | 完整行序列进入页面切分器，结果为明确的 `LVRendPageList`；段距行可标记 `RN_SPLIT_DISCARD_AT_START`，页内保留、移到新页首时舍弃 | 页面边界应有可复用的首末游标；段距应与正文行预算分开，不能只从当前滚动缓存推断唯一页界 |
| [FBReaderJ 官方旧开源版 `ZLTextView.java`](https://github.com/geometer/FBReaderJ/blob/master/fbreader/app/src/main/java/org/geometerplus/zlibrary/text/view/ZLTextView.java#L868) | 保留前/当前/后三页及首末游标；先判断完整行高度，再处理该行的段后间距 | 保留已经切出的页面，页尾间距不应单独否定已容纳的正文行；该证据不代表现行商业版 |
| [Foliate 官方 `paginator.js`](https://github.com/johnfactotum/foliate-js/blob/main/paginator.js#L290) 与 [Readium 官方分页说明](https://readium.org/css/docs/CSS03-injection_and_pagination.html) | 采用 CSS 多栏分页；Foliate 使用固定页尺寸移动，字体完成加载后重排并恢复 Range 锚点 | 可借鉴明确的页面与位置身份；直接换 WebView 会涉及高亮、选择及现有 Flutter 阅读交互迁移，本轮未引入 |
| [CSS Fragmentation §5.2](https://www.w3.org/TR/css-break-3/#break-margins) | 非强制断页处相邻块的 margin 截为零 | 页内段间隔与页首/页尾空白需要独立规则；本项目目前的固定 padding 不能直接等同 CSS margin |
| [W3C 中文排版需求 §7.1.1.5](https://www.w3.org/TR/clreq/#considerations_when_designing_the_type_area) | 版心设计结合字号、页行数和行距；一般保持行距一致，行高等于字框高度加行间距 | 固定行网格可以作为后续分页方案，不能将逐页拉伸行距冒称为已核实的主流默认行为 |

这些是公开方案对照与本项目独立实现，不复制 GPL 阅读器代码。设正文可用高度为 `H`、同字号字体安全高度为 `G`、相邻 baseline 进距为 `P`，没有额外段距时，完整 `N` 行占用：

```text
used = G + (N - 1) * P
N = floor((H - G) / P) + 1       （H >= G）
```

页内确实存在段间隔时，另加其总和 `S`，即 `used = G + (N - 1) * P + S`；页末之后或新页正文之前的装饰段距应单独处理。混合字号/字体的页面需使用各行安全上下边界和实际 baseline，不直接套统一 `G` 的简化式。该公式是明确预算的设计推导，不是本轮已经全部替换成固定网格的声明。

若选定 `N` 后要求底部对齐，可以解出 `P_eff = (H - G - S) / (N - 1)`；但各页段落数量不同会使 `S` 改变，从而让行距逐页变化。此次没有查到上述官方产品默认如此拉伸的依据，因此本轮保留用户字号、行距、段距、页脚和标点规则，先修正字体安全行预算、透明快照、已访问页面边界和异步 seek。未来若整章生成不可变页面目录，应同时解决字体加载身份、内存/首章延时、自由滚动桥接及 TTS 跨页范围；该迁移方案尚未作为本轮完成项。

### 比例模型及严格的可行条件

设F为字号/基准字体高度，G为实际字体安全盒高，L=aF为两行基线的进距，S=bL为跨段额外增加的距离；S不包含已经计入L的普通行距。正文可用高度为H。统一字体/行高、正文充足、首行安全盒顶对齐时：

```
U(N,m) = G + (N-1)L + mS
R = H-U
T = (H-G)/L = K+r，K整数，0≤r<1
```

m是这一页可见行之间的真实跨段次数，范围0..N-1。若`Kb≤r<0.5`，所有分段组合均容纳K+1行，且`R=(r-mb)L`；绝对余量不超过rL，段落导致的波动不超过KbL，二者都严格小于半行。可先选K和r再反解`L=(H-G)/(K+r)`及`a=L/F`，给出`b≤r/K`的可行区间。例如K10、r0.25时b最多0.025；若L62.4，则额外S至多约1.56逻辑像素。这是固定字体、视口及受控小段距的充分条件，不是任意明显段距的承诺，也不能默默改变用户固定行距。

只验证无分段与每行一段两个极端不够。独立内存计算反例G=F10、L20、S10、H70：无分段4行底边10/30/50/70，R0；每行一段3行底边10/40/70，R0；第一段3行再换段，前三行底边10/30/50，下一行底边80，放不下，R20（整行）。中间模式反而差。任意固定正S都可在`H-G=KL`且跨段出现在最后可容纳行之前时产生这一台阶。

主代理在内存穷举T10.25、每组4096种跨段序列，子代理独立推导一致：

| b=S/L | 最小R/L | 最大R/L | 波动/L |
| ---: | ---: | ---: | ---: |
| 0 | 0.25 | 0.25 | 0 |
| 0.02 | 0.05 | 0.25 | 0.20 |
| 0.025 | 0 | 0.25 | 0.25 |
| 0.05 | 0 | 1.00 | 1.00 |
| 0.20 | 0.05 | 1.05 | 1.00 |

倍数为有理数p/q时，累计段距模L确实每q次循环；它控制余数相位，但实际内容只能取连续前缀，不能自由挑选所有N/m组合中的高度。下一行跨段可能需要L+S，离散门槛可使余白在相同余数上再多一个L。用误差累加器分配亚像素/网格舍入，可把累计舍入误差限制在半个网格内；该结论不能替换页底余量或波动的上界。只压缩页边段距也不能解决无分段页面本来就可能剩0.7L的情形。

### 建议的统一实现及验收顺序

先由真实字体和可用宽度完成横向断行，再统一纵向位置，避免每段独立padding造成网格相位不同。[Flutter LineMetrics](https://api.flutter.dev/flutter/painting/TextPainter/computeLineMetrics.html)提供已排版行的ascent/descent/baseline等度量，但字号本身不能代替实际字体安全高；标题、回退字体、缩放和特殊高字形须作为真实约束。

1. 先提取不可变LayoutRevision/LineRef/PageLayout，页面包含原文范围、每行baseline/安全范围、段界、下一页位置；提交一次，裁切、高亮、起读和保存位置全部派生，清除多份独立页面真相。
2. 分开显示与语音版本，合并视口定位适配；保留原文→display→tts映射和事务/意图保护，在新路径通过旧反例后逐条退役flow换行及修正回路，不保留两套同时生效的分页器。
3. 比例方案先约束“固定行距/小段距”可行区间。若需要明显段距，又要求普通完整页接近固定页底，可对实际连续行前缀N及其m求`L_eff=(H-G-R_target)/(N-1+mb)`，保持`S_eff=b*L_eff`，选最接近目标行距且满足安全/容差的候选。总比例可以保留，但不同行段构成会导致页面行距改变，必须明确其许可范围；固定微小容差不能无条件保证所有页面都可解。章节末页、强制标题分页和超高行应允许自然余白。
4. 不枚举2^(N-1)种不属于当前原文的排版。真实文本按实际段界累计行/段距前缀即可，采用按章节/附近窗口惰性准备并缓存；反例验证再穷举分段模式。字号、视口、字体加载和过滤改变时建立新布局版本，从原文锚点一次恢复。

验收先覆盖数学边界、全部分段模式、真实字体安全范围和确定的不可解案例；再保留快速过滤三级交错、跨章/长段前后翻页不漏重、逐帧稳定画面及TTS页首一致性。固定倍数方案与有限幅匀排是不同约束，不把‘去掉段距’或‘能循环余数’写成用户目标已完成。下一阶段如实施，应沿用当前固定工具/离线入口并交付对应新版本；本轮审查不冒称新分页器已实现。

## 用户澄清后的半字网格与段距预算方案（2026-11-21，数学研究，未实现）

用户明确：不要求任何段落组合铺满页面；行间距挡位按文字高度的倍数定义，纵向台阶约半个文字高；末行之后不计行距或段距。进一步确认目标是所有常规正文页的页底余白总波动不超过半个文字高，不是允许多个半字台阶。此前用两个极端铺满举例没有直接对应此目标，本节按新定义给出建设性的可实现模型，不逐页改变正常行距。

### 统一定义与页尾规则

G为普通正文文字的安全高度，q=G/2为基础量子，L=kq为选定挡位的固定基线进距（k≥2），额外段距s_j=u_j q。普通行间空白为L-G；段界处文字间空白为L-G+s_j。第一行文字安全盒顶端从页内0开始，各常规行使用固定L；只在页内真实段界处添加额外s_j。

```
U = G + (n-1)L + q Σu_j
R = H-U
```

只有n-1个行间隔，页首之前和末行之后均没有附加间距；不能把一个完整含尾距的行盒再次加到末行上。页高H只用安全正文区域，不含标题栏/页脚。章节末页、强制标题页、特殊高字形不是‘内容充足的普通正文页’，不以拉满处理它们。

[W3C Rhythmic Sizing草案](https://www.w3.org/TR/css-rhythm-1/)把行盒/块盒尺寸量化到步长的整数倍；[W3C Line Grid草案](https://www.w3.org/TR/css-line-grid-1/)讨论逐页重新建立行网格。它们支持统一步长的设计方向，但不自行提供本应用‘页底总波动≤q’的证明。下述预算与界限是本次独立推导，不冒称成熟产品已直接采用或Flutter已原生提供。

### 先固定页底区间，再分配段距格子

无内部段界的最长常规页确定参照：

```
N0 = floor((H-G)/L)+1
R0 = H-G-(N0-1)L

R0≥q时：I=[R0-q,R0]
R0<q时：I=[R0,R0+q]
```

I对本次字体/字号/视口/挡位固定，宽度恰为q，包含无段界页的R0；不要求R本身小于q，更不要求所有页面底齐。只要不同页都落入I，总波动就不超过q。

对真实连续行前缀n（1..N0）统计其实际内部段界数p，令A_n=H-G-(n-1)L。总段距格子数t必须满足：

```
ceil((A_n-I_hi)/q) ≤ t ≤ floor((A_n-I_lo)/q)
```

然后与允许段距范围p*u_min..p*u_max求交，整数交集非空才是可行页面。正文顺序和横向断行完全不变。p=0只能t=0；p=1由唯一段距独自承担总预算，不能假装任意固定s都自动可解。可在可行候选中优先较多文字行，再最小化与名义段距的差异。

总预算采用循环/相位方式分配：

```
u_j = floor((j+1)*t/p)-floor(j*t/p)，j=0..p-1
```

各段距只取相邻两个整数挡位，总和严格等于t。循环用于分配已经满足页底约束的配额；它不是先取模再把多出的整行忽略。实际段距及行基线必须保存在同一PageLayout中用于绘制、命中、翻页和TTS。

### 一个保留正段距的通用充分条件

若允许页内额外段距为q..L（u_j=1..k），且R0≥q，则任意普通段界组合都有可行前缀，不需要改变正常行距，也不必把页内所有段距压成0。

证明：令j=N0-n，p_n为n行前缀的段界数。目标t可选jk或jk+1。f(n)=p_n+n-N0随n每次增加1或2，从非正走到非负；第一次f≥0时p_n=j或j+1。前者取t=jk=k*p_n，后者取t=jk+1，均满足p_n≤t≤k*p_n。p_n=j=0为无段界页，取t0。q步长分配即可使R落入I。

R0<q时，同样推导使用t=jk。j≥1仍满足段距1..k的范围；唯一可能需要零段距的情况，是最大N0行中只有一个段界，而且恰在末行之前（j0、p1）。此时允许省略这一个页边额外段距，仍保留正常L，不压字、不删行。若连这项页边例外也不允许，则该组约束没有通用解，须明确返回不可解，而不是偷偷改正常行高。

该充分条件的真实代价是：额外段距可以在q至L之间伸展，个别页边额外段距可省略；段距不是全书处处相同的一个常数。用户若要求更窄的段距范围，算法仍可求解，但必须检查每个真实前缀的预算交集，不承诺总能满足界限。它也不保证保持名义段距的长期平均值，除非再证明跨页配额可偿还。不能为满足公式而无说明地增加整页留白或减少可用正文高度。

## 最新前提：固定行距、固定段距的精确判据（2026-11-21）

用户现已明确：同一挡位下全书使用固定行距和固定段距，不逐页调整，不采用循环配额的可变段距；末行之后不计行/段间距。此前半字网格配额方案因需要改变各段实际间距，不再作为本需求候选；其12万/72万数值检查不证明固定间距满足目标。本节完全排除动态段距、页边省略和逐页正文高度补偿，独立重新推导。

### 模型与自然分页的必要充分条件

G>0为统一文字安全高，L≥G为固定基线行进距；普通行间空白为L-G，段界处文字间空白固定为L-G+S，其中S≥0是固定的额外段距。用户若以实际文字间空白定义‘段距’，应先扣除已包含的普通行间空白，再得到S。H≥G为固定可用正文高度。只讨论正文充足的常规页、任意真实段界排列、固定页首基准和自然最大连续前缀分页，要求总波动W=G/2；章节末页/标题和可变高字形另行处理。

```
C=H-G
K=floor(C/L)
r=C-KL，0≤r<L

K+1为没有额外段距时的最多行数。
n行、m个页内段界的高度：U=G+(n-1)L+mS
R=H-U
```

只有n-1个行间隔，完全没有末行尾距。精确必要充分条件为：

```
所有段落排列的页底总波动≤G/2
当且仅当
K*S ≤ min(r,G/2)
```

K0或S0自然包含在此式中。该结论不要求绝对余白≤半字，也不要求任一段落排列铺满页面。

证明分两支：

1. 若KS≤r，所有可能排列均容纳同样的K+1行；m可以为0..K，余白集合正好为r-mS，总波动KS。因此再要求KS≤G/2即达标。
2. 若KS>r（此时K≥1、S>0），取m=floor(r/S)≤K-1，R'=r-mS∈[0,S)。存在具有K个内部行进、m个段界的真实前缀，余白R'；也存在具有K-1个内部行进、同样m个段界的真实前缀，余白R'+L，且下一行恰好跨段。下一行需要L+S，而剩余R'+L不足，所以后一页自然结束。这两种排列的余白相差整整L≥G>G/2，必定失败。两页都不需要铺满，证明也没有计入末行之后的段距。

这表明固定间距下没有额外的循环规则能绕过容量门槛。若有理倍数导致余数循环，但触及第二支，真实余白中仍出现相差一个L的状态。

### 直接计算全部余白，而非只看两个极端

所有可实现的自然页尾余白可写为：

```
R=C-tL-mS
0≤t≤K，0≤m≤t
0≤R<L+S
```

t为内部行进数、m为其中的段界数；最后一个条件表示下一行可以是跨段行并且确实放不下。任意满足条件的t/m都能对应真实的连续段落前缀，因为所有进距均为正，最终前缀放得下就意味着此前前缀也放得下。该谱能以O(K²)生成；仅求上下界时，对每个t求合法m整数区间即可降至O(K)。因此无需枚举指数规模的整页排列。

主代理以内存JS枚举G20、L20..40步长2、K0..12、全部整数r0..L-1、S0..20，共90,090组，实际余白谱与判据无不符；KS>r分支的跨度均至少L。子代理独立枚举整数G1..5、L=G..12、C0..80、S0..12的52,650例，再加20,000组随机连续参数，共72,650例，未发现反例。这是数学与内存计算复核，没有应用构建或真机测试。

### 固定倍率能选在哪里

令a=L/G、b=S/G、c=H/G-1。条件等价于：

```
K=floor(c/a)
K*b ≤ min(c-K*a,1/2)
```

指定K≥1和固定b后，可行行距倍率区间为：

```
a ∈ (c/(K+1), c/K-b] ∩ [1,+∞)
且 K*b≤1/2
```

所以存在特殊的固定倍率组合，但正常行数会限制额外段距：最多十一行时K10，额外S至多0.05G，还必须满足r≥10S。若额外S=0.25G，通用保证最多三行；S=0.5G最多两行。将半字q作为额外段距的最小正台阶，在常规三行以上页面无法保证总波动≤半字。

同一固定正倍率也不能对任意字号、横竖屏视口作无条件保证：当H-G恰好为KL时r0，任何S>0且K≥1都会进入第二支。应对每个字号/视口/挡位验证固定参数，而不是在某个页高通过后宣称所有设备都成立。

以下均为示例逻辑像素，非实测手机字体：G40、L60、H686，K10、r46。

| 固定额外S | 全排列最小余白 | 最大余白 | 总波动 | 半字20以内 |
| ---: | ---: | ---: | ---: | --- |
| 1.5 | 31 | 46 | 15 | 是 |
| 2 | 26 | 46 | 20 | 是 |
| 3 | 16 | 46 | 30 | 否 |
| 5 | 1 | 61 | 60 | 否 |

S20时，11行且两处页内段界可剩6；10行且两处页内段界、下一行跨段时可剩66，因下一行需要80放不下。这里没有拿无段与逐行分段两个极端比较，也没有让任何一页底齐。S2时实际段界文字空白固定为22（普通空白20+额外2），整本不动态改变，确实可以满足目标。

### 提前分页不能无代价地绕过行数限制

如果允许提前断页但仍要求所有排列的余白落入宽W<L的同一区间[A,A+W]，对应可选前缀高度带为[H-A-W,H-A]。令H'=H-A。某序列存在落入带内的前缀，当且仅当以H'为容量的最大连续前缀余白≤W；带宽小于最小行进距L，带内至多有一个可选前缀。

因此还需某个固定H'≤H满足K*S≤r'≤W，其中K=floor((H'-G)/L)、r'=H'-G-KL。S>0时最大K可写为min(floor((H-G)/(L+S)),floor(W/S))。S=W=G/2仍至多两行。理论上可以用大量固定空白换取这种稳定，或所有页只放一行；它们不构成正常阅读的实用解。前面的自然分页判据没有冒充对所有提前分页策略的无条件结论。

本轮结论：固定倍数关系在小额外段距及合适页高相位下可严格达标；明显段距配合正常多行容量时，无法对任意段落排列保证半字总波动。可据判据制作固定参数可行表；不再引入用户已排除的动态调整作为兜底。当前应用源码、版本及APK均未变化，没有暂存、提交、推送或PR操作，也没有生成临时文件或截图。

## 行数不受固定限制：对真实正文联合选择页尾（2026-11-21，重新计算）

### 全书联合求解

先取得真实字体/宽度下的视觉行序列及段界。节点i表示已消费前i行，边i→j代表本页取连续行[i,j)。只计其中的页内段界p(i,j)：

```
U(i,j)=G+(j-i-1)L+S*p(i,j)
R(i,j)=H-U(i,j)
```

U≤H才是合法边。对候选余白区间[A,A+W]，仅保留R落入区间的边，再用DAG最短路径/动态规划寻找从0到N的完整阅读路径。目标采用‘总波动≤W时最少需要几页’，不预设各页几行。扫描所有合法余白值作为A即可覆盖最优解：任一解实际最小余白本身就是某条边的余白值。W<L时每个起点在固定高度带内至多一个页尾，但对不同高度带进行全书可达性检查仍然必要。

本轮主代理写了独立的内存DP，默认所有页包括最后一页都参与指标，并对120组14行分段序列用另一套完整断页递归检查；最少页数无不符，累计访问3136个剪枝后断页状态。子代理独立DP亦找到相同的9行实例。没有把m/n当作可自由拼出的文本，而是每次按真实连续行段界计数。

### 当前结论

固定非零段距与联合选择页尾确有可行区；应按真实行序列查找满足共同余白区间的最少页数，而不是只用单页最大填充反例否定。较小固定额外段距可以保留密度；较大段距的严格半字号波动可能付出大量页数和更大的固定留白。‘波动变小’不能代替‘留白变少’，两个指标必须同时报告。章末页是否豁免会显著影响结果，当前研究同时验证两种政策，未替用户锁定。

令X为按固定L/S累积的行坐标，页[i,j)的占用为G+X[j-1]-X[i]。对全书共同I=[A,A+W]且W<L，一个起点最多一个页尾满足该区间。因此原型枚举所有候选A，再逐页二分定位，不需要通用DP；任何合格方案以自身最小余白为A都会被复原。正文行容量C下候选由(n,p)决定，最多C(C+1)/2种；可按页链O(P log C)走查每个候选，行坐标空间O(N)。原型目标是满足硬上限后最少页数，同页数优先更小最大余白；不动态改任何间距。

验证包括：九行[1,2,6]三页反例、五行末页政策反例、120组14行序列与另一套完整断页递归比较、不同固定段距/分段结构的容量表、普通isolate执行纯数值规划、真实CJK无损行表交接。子代理另对1..8行全部段界排列、章界强制/不强制、末页计入/豁免共1020个短情形检查三目标Pareto，区间扫描与枚举所有分页相同。

一行一页在原始无容量限制下始终可行；因此只有加入明确容量/已提交页/特殊高行等约束后，才可能报告无解。不可把行数偏好暗中当作数学不可能。本轮原型保留最少页数目标，避免为了漂亮的波动数字默认退化为极短页。

### 字号与字体安全高度必须分开

早期纯数学样例用同一个G表达基准字高和安全框。真实字体验证显示二者不能直接混用：UI的TextStyle.height以字号F为倍数，文字安全框还受字体ascent/descent、fallback及缩放影响。本轮以F/2作为波动上限，G仅用于防裁切，避免扩大用户目标。

### 可落地的单一布局模型与迁移顺序

1. 先抽共享LineLayout和不可变PageLayout，保持现有行为。行记录保存真实断行的UTF-16显示区间、原文映射、baseline/ascent/descent/安全框、段界；页记录保存首末原文锚点、行ID和实际位置、固定L/S、余白及共同I、前后页ID。

4. 将根isolate分批行测量、worker精确规划、可取消与sealed计划缓存接入，再分别验收当前章/全书保证。特殊高行、标题、孤行、重叠保留行、已提交页等额外约束必须进模型，不暗中删字、改S或放宽W。

## 1.3.19 固定段距与整章共同区间接入

以上研究结论保留为当时事实。用户随后明确要求四档 0/.05/.1/.25、默认 .1，并纠正“段距设置与联合选页”不应被当成两个待选择范围；本次一起接入生产。详细行为与当前验收见 [1.3.19 交付记录](releases/v1.3.19.md)。

`ReaderLineLayout` 对完整原始 span 和实际字体环境测量，返回不含原生对象的数值行表；不在 worker 调用 dart:ui，也不把页子串重新排版。`ReaderPagePlanner` 接收实际每行 top/bottom、锚点边界和固定页，页占用为 bottom[end-1]-top[first]；固定 L/S 下用行数及页尾作为变量。对于窄区间使用唯一可行尾的快速路径，存在特殊高度时仍有完整 DAG 路径。旧测试原型委托同一生产服务，不再保留独立候选搜索。

候选只按精确 double 去重，并用事件集合跳过等价区间；不能继续引用旧原型 O(N) 内存和旧计时作为本生产实现的性能结论。当前可行边 E 最坏 O(NC)，空间 O(E+N)；搜索 K 个实际不同区间时，窄路径每轮约 O(N log C)、一般路径 O(E)。数值计算在后台；字体测量只能协作让出，单个原生 layout 无法抢占。首屏仍只测附近窗口，第一轮联合翻页会增加当前章的完整测量成本，后续复用至字体、文本、视口或入口改变；没有全书预排版或跨重启字体缓存保证。

整合中发现并修正两项设计偏差：一度独立规划入口前缀/后缀，不能证明整章共用 I，现改为完整章行表、显式入口边界及已显示固定页一起求解；一度允许后台建议直接参与当前页裁切，存在导航后迟到改页风险，现仅实际翻页启用切片，并按导航/布局代次取消。原入口页、标题页和章尾的豁免显式保留，固定普通页不允许被自动豁免。重叠保留行与上下滚动维持既有行为，数学无解时保留完整行分页；不对全书或任意新入口跨计划作共同 I 承诺。

测试 oracle 也区分两种真实政策：联合页严格核对实际绘制行与计划的完整切片，原入口页仍检查最大可容纳前缀；不能继续要求联合页一定填满。新用例还对实际字形占用、数值余白、半字号极差及固定物理行进距分别核对。列表可能保留 inactive renderer，其虚拟坐标不能当可见原文；朗读 oracle 现在依据实际活跃 item 身份，再检查其投影文本，避免重复网址段被反查到首个同文本段。这些更正不移除原文连续、不漏不重、反向可逆、精确 TTS 偏移和过滤锚点断言。

## 1.3.21 段距切换恢复与页面容量保护（本轮实现，最终验证待补）

本节追加本轮新结论，不改写上述研究和 1.3.19/1.3.20 的原始方案、运行结果与交付事实。用户反馈切换段距后下一页行数异常、切回原档仍不一致，并要求删去较小的 .05/.1 档。当前版本为 1.3.21（55），段距固定四档改为 0/.25/.5/1 倍字号、默认 .25；旧 .05/.1 和缺失/非法值回到 .25，已有合法 0/.25 保留。新增菜单 .5/1 不改变固定行高、缩进偏好或朗读设置。

### 入口切片和窗口身份

只恢复首源行/top 不足以恢复联合页：旧页 A..B 在重排时丢掉末边界后，会按最大完整行临时填成 A..C；下一次翻页又把临时结果当作已显示入口固定，后续从 C+1 开始。因而“同段距、同首字”不代表同切片链，切档再切回仍可表现为下一页不同。原来非几何设置也无条件清空 pageEnd/history，会触发相似变化。

本轮按完整布局身份保存最近四份数值切片，每份最多 385 个切点记录，包含已提交页及附近建议的首末键、豁免标记和可用前驱关系。恢复源锚点后，在撤去重排遮罩前恢复匹配布局/首行的数值末边界。缓存不保存原生图片、TextPainter 或字体对象，不作跨重启持久化；实际文字/几何身份变化仍需正确失效。非几何设置继续保留现页末边界和页历史。这解决已缓存布局的切回恢复，不把首次遇到的新字体、新几何或所有未来路径宣称为全书唯一规范分区。

有限规划窗口现在以源章节为中心，向前按整章累计到 2H、向后按整章累计到 3H 的相邻文字，遇书端停止；H 是当前正文高，整章扩展可超过阈值。在同一源章节内改变当前行，不再改变前后窗口的选择依据。新计划安装时退休源区间相交的未显示旧建议及相应前驱关系，保留已提交切片，避免混用不同窗口留下的候选。临时边页仍扩展后再显示；异步结果须同时匹配布局和导航代次。

### 严格半字号目标与可读容量

新增 420 组纯数值研究：F=39，L/F 为 1.2/1.4/1.6/1.8/2/2.2/2.4，S/F 为 .25/.5/.75/1/1.5，H 为 640/760/880，结合四种段落密度。输入按固定 L/S 生成，求解器只选页尾；.75/1.5 仅是研究值，不是菜单选项。该模型以 F 同时作为合成行安全高度，不冒充真实手机字体的字形框或 native strut 测量。

这取代生产路径不惜容量满足窄余白区间的选择；不否定旧研究中确实存在的小波动可行输入，也不改写旧版当时的验收结果。固定间距下，不再对任意字号、段距、段落密度、入口或有限窗口组合承诺普遍半字号上限；当前取舍是页面容量、源文完整与真实指标优先。

## 1.3.22 硬余白带、原生几何预算与双向固定行数

本节追加用户最新约束下的实现与数学依据，旧版方案、运行数字及交付历史保持原事实。用户明确普通页底余白波动不得超过半字号，允许调整实际段距数值，菜单只保留四个档位。因此 1.3.21 的 `solveReadable` 宽区间回退不再适用于生产；“固定 .25/.5/1 倍字号，再强行找窄余白带”也不再是本版模型。版本为 1.3.22（56），最终完整验证与交付仍待补齐，见 [版本记录](releases/v1.3.22.md)。

### 纠正先前推断：共同格点也不足以保证容量

F=39、P=1.2F=46.8、S=.25F=9.75、H=760 的两种正文密度，已经否定“.25F 普遍可在硬半字号内至多少一行”的推断。长段最长 16 行，其允许 15/16 行的余白是 65.8/19；每行一段时最长 13 行，其允许 12/13 行的余白是 98.95/42.4。两集合最近距离 23.4，大于 W=19.5，足够长的两个内区无法共同满足该带宽及容量条件。允许长段退至 14 行才可能与 12 行短段兼容，但已经损失两行。

取 S=P 也不充分。H760、F39、P62.4，普通段界使行间步进为 2P，少数同段间隙为 P。将四个孤立 P 间隙按 13 行间隔放在足够长正文的内部，W<P 要求普通页具有同一整数跨度 mP。奇 m 不能覆盖长的 2P 内区；偶 m=2k 的合法页具有 k+1≤6 行，而且孤立 P 间隙只能落在页界。13 无法被 2..6 整除，因而所有非零跨度都无法贯通，只剩一行普通页。真实首尾豁免不能修复内部矛盾。共同 gcd 或有理倍关系不等于页切图存在完整路径。

有限矩阵研究与这些反例均保留在数值测试中；不能把有限模式通过宣称成所有段落组合的证明。新方案改为先为共同几何求安全的 S 和 K，再用同一套确定分组显示，避免依赖任意旧 S 的可行性。

### 字体测量的身份、证据与不足

阅读准备 worker 收集全书唯一 grapheme 库存；真实 `TextPainter` 测量仍在 UI isolate，不能搬到普通 isolate 调用 dart:ui。`ReaderFontGeometry` 在相同字体、缩放、语言方向、locale、正常字重固定 strut 身份下，分别测正常／粗体库存、单行、多行及跨段步进，得到原生基线间距的区间 Pmin..Pmax，而不是用 F×设置行高冒充真实 P。

相对共同基线的 tight 上缘为 tmin..tmax，下缘为 bmin..bmax。行内混合字体使用同一视觉行各 run 安全框的并集；远锚点恢复也按这一行范围选择，避免原文 20000 落入另一 run 后被恢复为 20005。为覆盖已观察到的每步原生浮点差，调用处对原生 pitch 和字形边缘另保守扩展 .001px，按整页内部间隙数累计，不能把每步误差当成只支付一次。

库存覆盖全书字符，不代表有限上下文探测已经覆盖所有字体回退或 contextual shaping。代码明确保留这一限制。字形包络与共同 P 区间是下面充分条件的前提，实际页门还须核对原生绘制结果；不能只因 `inventoryComplete` 为真便宣称全文证明完成。

本轮库存测量优化选正常／粗体各一次完整 UTF-16 selection，直接遍历其原始 tight run boxes。这里不能先做全库存 union，否则会丢失较矮 run 的 tmax/bmin；也无需逐 grapheme 再做约 2U 次选择查询。[Flutter 官方 BoxHeightStyle 定义](https://api.flutter.dev/flutter/dart-ui/BoxHeightStyle.html)明确 tight 按 run 高度返回，而 max 才把同行各框统一成该行的最大高度。[getBoxesForSelection 的规则](https://api.flutter.dev/flutter/painting/TextPainter/getBoxesForSelection.html)说明只完整返回被选择范围包住的 glyph，多 code unit 字形的部分选择会被排除，因此使用完整选择避免这种边界丢失。此依据支持本次查询方式，不证明库存拼接已经覆盖每种正文上下文。

[LineMetrics.height 的官方说明](https://api.flutter.dev/flutter/dart-ui/LineMetrics/height.html)另指出行高存在 ascent/descent 求和后的取整差，进一步说明不能把 nominal F×L、某一个 line.height 或整数行框代替逐基线观测。库存排版依然在 UI isolate，有真实首轮成本；旧逐项与 whole-selection 参考测量受缓存和执行顺序影响，最终优化后的耗时、首轮峰值与性能验收待主流程实测填写，不将热缓存参考数字写成手机首次加载承诺。

### 固定 K 的充分条件与四档定义

令 F 为系统文字缩放后的字号，H 为实际正文可用高度，P 为原生基线步进，S 为固定额外段距。定义：

```text
Gmin = bmin − tmax
Gmax = bmax − tmin
Δfont = Gmax − Gmin
Δpitch = Pmax − Pmin
Wsafe = F/2 − 0.5px
```

一张 K 行普通页具有 K−1 个内部行间隙；无论段落怎样分布，额外段界数 q 都在 0..K−1。所有实际占用 U 都被以下区间包含：

```text
Umin = (K−1)Pmin + Gmin
Umax = (K−1)Pmax + Gmax + (K−1)S
```

因此同时要求 `Umax≤H` 与 `Umax−Umin≤Wsafe`，对 K≥2 得到：

```text
baseMax = (K−1)Pmax + Gmax
Smax = min(
  Wsafe − Δfont − (K−1)Δpitch,
  H − baseMax
) / (K−1)
```

只要预算非负，这个包含关系覆盖任意内部段界组合，不依赖书中一行段／长段的比例，也不要求它们按特定顺序出现。固定的是同一几何内的 P 和 S，不做逐页拉伸。余白区间统一为 `H−Umax .. H−Umin`，不是每个窗口另选一个带宽相同但位置不同的区间。

K 的选择同时核对两个容量边界：`Nworst=floor((H−Gmax)/Pmax)+1` 保证最坏字形也能容纳，`Ndense=floor((H−Gmin)/Pmin)+1` 给出该前提下局部真实最大容量。若 Nworst 已小于 Ndense−1，就明确不支持；否则只在仍满足 `K≥Ndense−1` 时，允许由 Nworst 减少一行换取段距预算。优先保留已有足够余量的 Nworst，不能用保守 N 再减一行却声称相对真实最大只损失一行。所有档位，包括零段距，共用同一个 K。

保存的四档为整数 0..3，界面为“无／一档／二档／三档”，默认 2；实际 S 为 `0、Smax/3、2Smax/3、Smax`。高度预算很紧时，各档可退化到同一零距离，硬带宽不扩大。真实可用高度只能容纳一行时支持 K=1，Smax=S=0，占用只由字形包络给出；这属于物理容量，而不是为凑窄余白而主动稀疏。源书末不足 K 行不能套上述普通页区间，应明确按源端短页处理。

### 同一边界双向取行及最终原生验收

生产只用 `ReaderPagePlanner.fixedRows`。以当前源行边界为 anchor，向前、向后各按 K 行分组；任一满 K 页实际 `bottom[end−1]−top[first]` 不在全局 Umin..Umax 或不适配 H，就返回不支持，不改成 greedy、DP 或更宽区间。纯数值原生坐标比较保留 1e−5px 的舍入公差，全局区间数值保持不变。

该路径消除“反向先顺排整段前缀、再显示末尾碎页”的方向偏差。例如前缀 11 行、K=5 时，向前取的是紧接 anchor 的第 6..10 行完整五行页，而不是顺排留下的最后一行。当前边界两侧同源完整分组，窗口起点只能制造不发布的外侧碎片。最近四份几何切片缓存的补偿已删除；旧 `solve`、`solveReadable` 和 `reversed` 保留研究／服务测试用途，不再决定生产页界。

只有真实书首／书尾不足 K 行片段可标记豁免；满 K 的真实首尾页仍必须通过同一门。物理章节、隐藏元数据占位、标题行、有限测量窗口边缘都不是额外豁免理由。临时窗口不足 K 行的片段不发布，接近时扩展源范围；迟到结果仍核对布局、导航和规划代次。

翻页提交前还核对实际视口坐标：首行 top 的绝对值≤.25px，末行 bottom 在全局 Umin−.1..Umax+.1 内。故任意两个通过验收的稳定普通页，其实际底余白极差满足：

```text
spread ≤ (Umax−Umin) + 0.2px
       ≤ F/2 − 0.5px + 0.2px
       = F/2 − 0.3px < F/2
```

初始进度恢复与过滤／几何重排也在撤去遮罩前执行实际验收，防止只在普通翻页校验而恢复入口漏检。普通归位选择最接近页顶的真实字形行，部分恢复后将该行对齐；不因几像素偏差跳过整行。实际页不支持时显示明确提示，保留硬约束；自由上下滚动、真实源端不足 K 的例外页不纳入普通分页极差承诺。段距或字体改变产生新几何后重新计算，不把不同几何的余白混作同一保证。

## 2026-11-22：1.3.23 纠正“极差很小但仍空整行”

以上 1.3.22 方案和验证数字保留为当时事实。本轮用户反馈许多字号仍空一整行，进一步明确实际最后一行到正文底部应小幅变化，而且不能放得下完整一行却留空。由此确认：只证明余白极差小于半字号，且允许固定 K 主动取自然最大容量 N−1，并没有满足新的绝对容量要求。此前测试允许少一行，正好遗漏了这一约束，不能继续用那些通过结果证明页底已经充分利用。

### 从窄区间改为接近正文底边的窄区间

继续令 F 为实际缩放字号、H 为真实正文高度、P 为原生基线步进，字体 run 相对基线的包络为 tmin..tmax、bmin..bmax。定义 `Gmin=bmin−tmax`、`Gmax=bmax−tmin`，行距区间为 Pmin..Pmax。新政策要求：

```text
Kworst = floor((H−Gmax)/Pmax)+1
Kdense = floor((H−Gmin)/Pmin)+1
Kworst = Kdense = K             // 自然最大完整行容量，不主动减一
Wsafe = F/2−0.5px
Umin = (K−1)Pmin+Gmin
baseMax = (K−1)Pmax+Gmax
0 ≤ H−Umin ≤ Wsafe
Smax = min(Wsafe−(Gmax−Gmin)−(K−1)(Pmax−Pmin), H−baseMax)/(K−1)
Slevel = Smax×level/3           // level=0,1,2,3；K=1时S=0
Umax = baseMax+(K−1)Slevel
0 ≤ R = H−U ≤ Wsafe
```

预算须非负且实际占用可容纳。要求 `H−Umin≤Wsafe` 后，空白最大片段本身也接近正文底边，不再仅约束 `Umax−Umin`。该充分条件覆盖任意 `0..K−1` 个内部段界，四档仍使用同一个 K、同一个全局预算，P 与各档 S 在相同排版几何内全书固定。首行之前、末行之后不计页外行／段间距。实际页仍核对可见首末 tight 行与预算，保留原生小量验收公差和预留量；数值包络通过并不免除显示前的验收。

这里的 H 取真实正文 RenderBox，而不是屏幕总高、页尾 clip 高度或 footer 之上的估算重复扣减。裁切页底至末行框，不会改变检验所用的真实正文底边；否则可以通过缩短 clip 把任何大留白“证明”为零。真实完整行容量检查另要求所有能放入实际正文的完整行都已显示，不能仅比较显示行数和政策 K 而互相自证。

### 固定字号不总有解，需共同选择有效行高与字号

本轮先在请求行高的 ±10% 范围内寻找一个原生可实现的 P，再用完整字体库存测量与上述政策准入。原生 P 不直接等于 `F×请求行高`；正文 span 和固定 strut 必须使用一致的有效行高。请求行高保留用户设置语义，有效值只对当前完整几何求一次，不逐页伸缩。

连续模型扫描也发现 5 组固定字号下无解的组合，因而不能保证仅调整固定段距便能覆盖所有字号。简化模型 F=G=50、请求 P=120、H=480 时，±10% 给出 P∈[108,132]。四行的最大占用为446，余白至少34，大于安全半字号24.5；五行的最小占用为482，超过480。更少行的绝对余白更大。这是连续模型的几何矛盾，并非只由原生量化平台造成；G=F 仅为该反例前提，不冒充实际字体包络。

用户已允许舍去不适配的字号。生产新增邻近可行整数字号选择：滑杆选择最近可行值，精调加减按方向跳过不适配值，界面显示实际字号。14..64 范围内仍无合法候选时明确拒绝，不退回宽预算或主动稀疏页。自动视口／文字缩放适配不把临时有效字号写成新的用户偏好，避免高度变化后持续漂移。

字体身份包含继承 TextStyle、strut、TextScaler、方向、locale、真实宽高、实际 F 与有效行高。不能只用 fontFamily 字符串、请求行高或旧 render 高度缓存当前字体几何。实际字号改变会重新断行，页界和行表按新身份失效，恢复依然以原文位置为依据。四档选择不能反过来选择不同 F 或不同 K。

仍由当前原文边界向两个方向每 K 行分组，不从测量窗口起点先贪心填满，再把靠近当前边界的短尾当作普通上一页。满 K 的真实书首、书尾与内部普通页同样通过实际预算门；只有真实源端不足 K 的片段可短页豁免。临时窗口边缘不足 K 的源片段继续不发布，物理章节和标题不新增例外。自由滚动与真实短页不纳入普通分页绝对余白承诺。

## 2026-11-22：倍数关系、余白定义及“是否需要全书排版”的研究复核

### 用户目标与实现附加条件须分开

用户的半字硬要求是同一几何内普通页面的 `max(R)−min(R)≤F/2`，R为实际末行下缘到真实正文底部的距离。1.3.23额外使用了每页 `0≤R≤F/2−reserve` 的绝对带，后者更强，不能归称为用户原定义。用户允许每页行数改变；全局固定K、对每个间隙都按可能跨段预算，以及统一行高仅允许请求值±10%，均为实现选择。避免故意漏排可容完整行、保持正常页顶位置，与上述余白极差约束是分别检查的条件。

39号字夹具的默认S约0.516px、最高S约0.774px已见最终日志；数值非零并不等同用户可辨识的段距。固定K通用预算把每页所有K−1个间隙都按潜在段界分摊，会严重保守；但也不能反向声称只去掉fixedK便能普遍得到显著段距，以下给出其数学适用边界。

### 倍数网格不等于所有格点都有完整文字行

理想同字形高度G时，一页k行、内部q个段界的占用为 `U=G+(k−1)P+qS`，余白 `R=H−U`。P为基线步进，S为额外段距，末行之后不计P或S。倍数关系可以统一单位，却不决定真实q，也不让每个网格点自动成为文字行底。

可核算反例：F=G=20，半字网格10，P=30，S=20，H=120。长段的行底20/50/80/110可装四行，R=10；另一普通页前三行底20/50/80，下一行跨段后行底130放不下，只能装三行，R=40。两页极差30大于半字10，虽然所有数值都是10的整数倍，且两页均已自然装入最大完整行。用30行源序列、仅第8行前设段界，可直接数值复现自然前缀分页；把这两种模式放在书中间即可避开真实首尾豁免，无须强制章节分页。此例反驳“半字网格本身就充分”，不证明所有其他倍数选择都无解。

### 不依赖全书正文的通用判据

在同G、固定页顶、自然最大完整行分页、任意段界模式、P>W的简化模型下，令 `T=H−G`、`n=floor(T/P)`、`a=T−nP`。对任意段界模式都保证余白极差不超过W的充要条件是：

```text
nS ≤ a
nS ≤ W
```

证明充分性：任意前n个行间隙即便全跨段也可容纳，n+1行自然装满，下一行最小增量P已放不下；R=a−qS，q=0..n，极差nS。固定行数在这里是证明结论，不是额外预设。

证明必要性：若a<nS，取q=floor(a/S)≤n−1，r=a−qS，0≤r<S。构造前n−1个间隙含q个段界；下一间隙若为P，最后一行仍放得下，余白r；若为P+S，最后一行放不下，余白P+r。两种自然满容量普通页相差整P>W。可按真实段界把两种模式拼入同一本书中间，后接正文，不能靠书首/书尾豁免修复。若a≥nS但nS>W，q=0与q=n已直接相差nS>W。

相较之下，1.3.23额外的绝对带要求是更强的 `nS≤a≤W`。这两个定义不能混用。主流程用384组简化数值组合枚举所有可能(n,q)末行占用，通用极差判据与枚举结果一致；这属于数学模型核算，不是手机字体实测。实际字形高度差异须另留原生包络/渲染误差预算。

这类判据只需正文H、字体原生度量及候选P/S，可以有限枚举计算，不需要全书换行排版。因此“计算倍数关系必须先排完整本书”的说法撤回。

### 可见段距与可变行数的正例

可见段距并非整体不可能。简化模型F=G=39、H=760、S=9.75（0.25F）、统一P=50.2时：长段页15行，U=741.8、R=18.2；单行段页13行，U=758.4、R=1.6。两者都是自然最大完整行，余白极差16.6<19.5。用75行长段加65个单行段、两种密度的交界自然落在页界，可构造10页双向合法的有限源序列。此例不证明任意混合顺序都有效。

若已证明所有段落恰为一视觉行，固定步进就是P+S；F=G=39、H=760、S=9.75、P=61.35时，每页11行、R恒10。已知有限周期的段落行长也可只枚举有限起页相位，而不逐页排完整本书。若有可靠段界上界Q，可按Q×S而非(n)×S给预算，但当前窗口观察的Q不能冒充全书上界。

### “全书排版”只是取得更多实际结构信息的一种实现

当前程序做过全书grapheme库存扫描；这不等于全书换行排版。原生真实行表按源块及邻近窗口懒算。倍数参数计算本身不要求这些全文行表。

若只验收当前及邻近页面，局部真实行表已经足够；但这不自动保证未测后文同一P/S永远有可用下一页。若希望利用某本书的真实结构得到比通用界更大的S，同时预先承诺全书及双向入口都可用，则需覆盖相应结构的信息。可以来自已验证的行表缓存、可靠周期/结构界、特定字体和内容的解析计数或全书实际断行；不能把“全书原生排版”当唯一数学途径，更不能把每次重新预排全书作为加段距的必经步骤。

下一步应先按原余白极差定义、小型倍数/相位枚举及局部真实行表验证参数，分开报告通用保证、已测范围、整书保证和无解情况。先前要求用户在“等待全书排版／后台全书排版”之间选择的前提过早，不作为当前既定实现决策。

## 2026-11-22：GPT-6.2 Astra / ultra 独立通用数学复核

用户明确要求启动GPT-6.2 Astra、ultra推理子代理，研究不依赖特定段落结构的通用方案。本节记录该子代理的独立结论、证明和适用边界；本轮未修改程序、运行项目工具链或构建APK。

### 定义与量词

H为真实正文高度，F为理论归一化字高，G为从固定页顶到首行底缘的高度，P=aF为实际基线行进距，S=bF为额外段距，W为允许的余白极差（理想模型取F/2）。名义字号、原生安全框与可见字高未必相同，因此先保持W独立，原生修正另列。

一页k行、内部q段界的占用为 `U=G+(k−1)P+qS`，余白R=H−U；末行后不计间距，原文必须连续覆盖。硬目标是max(R)−min(R)≤W，不额外要求R≤W。正常阅读模型另假定页顶固定、各页取自然可容的最长完整前缀；若允许提前分页、页顶移动或极低容量，必须分别计算，不把它们混成用户明文要求。

以下通用定理研究任意段界排列，且P>W。理论正例中的S≥.25F是‘明显段距’研究目标，不是用户新增的精确感知阈值。

### 自然装满的充要判据：行数固定是推论，不是预设

令T=H−G，n=floor(T/P)，A=T−nP，0≤A<P。恒G模型中，对任意段落排列都保证普通页余白极差≤W，充要条件是：

```text
nS ≤ A
nS ≤ W
```

若nS≤A，前n个间隙即便全跨段，n+1行仍可放下；第n+2行即便完全同段也放不下。因此自然分页每页恰n+1行，R=A−qS（q=0..n），极差nS。这里没有A≤W的条件。

若A<nS，取q=floor(A/S)≤n−1、r=A−qS，0≤r<S且r<P。前n−1个间隙含q个段界，末间隙为P时n+1行能放下，余白r；末间隙改为P+S时最后一行放不下，余白P+r。两种自然满容量普通页相差整P>W。可用前导页、真实跨段间隙和后续守卫正文把两种见证拼进同一本书内部，首尾豁免和非强制章界均不能消掉反例。若nS≤A但nS>W，全无段界与全有段界已经相差nS>W。

因而，允许每页行数变化并不能提升任意段落排列下的通用最坏容量；这不是先把K固定后得出的限制。

### 真正联合F/a/b的通用构造

设g=G/F、w=W/F，选n≥1、a>w、b>0，满足nb≤w；再取0≤x<a−nb，令：

```text
F = H / [g+n(a+b)+x]
P = aF
S = bF
R/F = x+(n−q)b
```

所有段落排列都自然装n+1行，余白极差为nbF。x决定共同余白带的位置，可以大于0，不把题意偷换成绝对靠底带。

若F离散，给定F/n/S后，P的精确筛选区间为：

```text
(H−G)/(n+1) < P ≤ (H−G)/n − S
nS ≤ W
```

一个字面满足全部间距条件的通用例：H764、理想F=G120、P288（2.4F）、S30（.25F）。任意段界排列都自然排三行，余白只可能为8/38/68，极差60=半字高。最大余白68超过半字高也不违背原题。它不是正常字号14..64内的可直接产品方案。

n2、a2.4、b.25、g1、H764对应完整可行字号区间为 `93.1707… < F ≤ 121.2698…`，不是只存在120这一个偶然数值。

### 通用容量的精确取舍

若希望每页至少K行，则必须有 `S/F≤(W/F)/(K−1)`。W=.5F时：

| 最低普通页行数 | 通用额外段距上限S/F |
|---:|---:|
| 3 | 25% |
| 5 | 12.5% |
| 8 | 7.14% |
| 10 | 5.56% |
| 15 | 3.57% |

因此b≥.25的通用方案最多三行。理想G=F、H≥640、F≤64、P≤2.4F的现实参考域内，n至少为floor((640/64−1)/2.4)=3，故此整个域没有S≥.25F的自然满容量通用保证。这是全域证明，不是试几个失败倍率。放大字号/行距把自然容量降至三行则可以得到字面通用解，所以不能宣称所有字号/行距下绝对无解。

较小b允许更高容量，例如理想H760、F=G64、P153.6、S8（.125F），任意排列自然排五行，R49.6..81.6、极差32=半字。该例仅展示一般取舍，不断言8px在这么松的行距下就满足用户认定的‘明显’，也不是原生实测。

### 提前分页不能免费消掉容量代价

若允许提前分页，但选定普通页共同余白带[d,d+W]，令C=H−d。固定页首的相邻候选行底至少相差P>W，所以带内至多一个合法页尾；若存在，它等同C下自然最长完整前缀。给定d，用C替代H后的通用判据是nS≤A≤W。

自由选择带位置时，通用最高行数为：

```text
Kmax = 1 + min(floor(W/S), floor((H−G)/(P+S)))   // S>0
```

令括号内为j，取C=G+j(P+S)即可实现；相对真实H下自然容量，最坏少floor((H−G)/P)−j行，长段上取等。若另规定至多少排L行，直接检查该差≤L即可，不凭‘不稀疏’含混判断。

S≥.25F时，即使允许提前分页也最多三行。参考域H≥640、F≤64、P≤2.4F内三行最多占G+2P+W≤403.2px，至少余236.8px；这不是用户期待的正常容量。

若允许整页首行上下移动，则把部分底余白移到页顶可以保留P/S而降低底部极差。对原余白极差D，只需允许页顶偏移极差max(0,D−W)，按每页max(0,R−minR−W)下移即可。这改变了稳定页首体验，不能隐瞒其代价当作正常页顶方案。

### 自适应看完一本书再选参数：量词不能偷换

上述单组参数判据先证明的是‘每组失效参数都有某种坏排列’，不直接等于‘同一本真实书击败所有字号’。

在有统一物理行数上限K0的抽象行流模型里，可以加强为共同坏行流：对k≤K0+1、0≤q<k，记录各候选占用是否可容、是否达到共同带下界的有限布尔表。即使F/P/S/d连续可选，也只有有限种这种取行/成败签名，等号可直接分类，不依赖切页阈值连续性。逐签名延长源行流，补普通行到已知新页首，再嵌入其失效见证并接守卫正文；已有内部失效不因延长源而复活。首个豁免页的有限可能偏移也逐一排除。若每一种允许签名都缺少通用保证，就能得到同一条有限抽象行流击败所有选择。若允许三行通用候选，便不能声称所有候选都失败。

同一份原文跨字号的换行另需证明，不能把每F分别生成的原文偷换为一本。存在条件版本：若可重复字的行框一致、每字可断行，且每个候选字号下都能以至多Mℓ个该字实现恰ℓ行独立段落，M有统一上界，则可构造入口相位无关的O(K0²)行局部坏块，再把所有有界长度‘该字/段界’原文块枚举拼入一本有限书，使各候选都遇到自己的坏块。此论证不依赖强制段内换行，但本轮没有验证实际Flutter、原文解析、缩进、技术切块与字体是否全部满足这些条件，不能声称已证明某一本真实手机小说通杀全部字号。

对有利实际结构，固定参数的可达余白集合会缩小，允许更多行或更大段距；覆盖这种结构的信息可来自可信结构界、有限相位、已验行表或实际内容检查。不等于必须先后台排完整本书。只靠H/字体度量已经可以决定最坏排列下的通用保证；要突破通用容量界才需要额外结构信息。

### 双向与真实字体修正

通用构造下每页消费n+1行，前后移动互为逆操作；真实末页不足n+1行时，若从书末独立恢复同一页序，需要保存尾页起点或其行数。任意书中位置建立的新页序也须保留锚点，不能把两个不同入口的页序要求混成同一固定页码。

对原生字体，将整页固定首行定位/末行下缘变化界为Gmin..Gmax，E=Gmax−Gmin，一组安全充分条件是：

```text
Gmax+n(P+S) ≤ H
Gmin+(n+1)P > H
nS+E ≤ W
```

逐行原生舍入还需加累计误差；固定行框容量与实际墨迹验收须分开。S/(P−Gink)可以描述段距相对普通墨迹间空隙的增幅，但不能代替用户的视觉判断。名义字号、原生框与字高阈值应在实现中明确，不靠量纲混用得到假无解。

子代理独立用完整可达余白集合 `{T−mP−qS | 0≤q≤m, 0≤T−mP−qS<P+S}` 核验整数P3..12、W1..P−1、S0..2P、T0..100，共121705组，与自然装满及指定带两个判据零处不符。可达集合也能研究P≤W，但上面的简式容量界以P>W为要件，不应越界使用。本轮为内存数学核算，未运行工程测试或生成临时文件。

### 上限的含义及验算

F 为字号，P 为相邻普通行基线距离，S 为段落边界额外增加的距离，G 为首行顶部至末行下缘所用的字体框高度，H 为正文高度，W=F/2 为本研究的半字波动上限。末行后不计行距或段距。同一组合的 P、S 固定，不按页面或段落数量调整。有限正文的最后一页不适用装满页波动约束。

对于任意段落边界分布、自然放入尽可能多的完整行，且 P>W 的理想固定字体框模型：令 n=floor((H−G)/P)、A=H−G−nP，则可行的最大 S=min(A,W)/n，余白范围为 [A−nS,A]。这是对任意段落分布的约束，不依赖某本书。虽然允许行数变化，当段落结构完全任意且每多一行需跨过 P>W 时，要对所有结构满足同一宽度 W 的余白带，上限内的通用方案实际上会保持 n+1 行；不能靠少放一行绕过这个界。允许对实际书籍做内容相关规划则是另一种问题。

CSV 分开列出 G=F、P=行距设置×F 的理想精确上限，以及本机原生字体包络的上限。原生测量使用 Windows 微软雅黑，覆盖样本汉字、标点、拉丁字母、数字及普通／合成粗体，共 663 个字体与行距组合。原生行进距包含舍入，并不总等于名义倍率×字号。安全值还对行进距上下各扩 0.001px、字体框上下缘各扩 0.001px，并从半字预算预留 0.5px；最终可用值向下取到 0.01px，绝不四舍五入突破上限。3315 组均通过该包络内的装入、不能再放完整一行和余白极差验证。

这里的原生安全值是所测字体与字符样本包络下的最大值，不是所有手机字体、回退字体或像素墨迹的全局最大值。尚未测量用户手机字体及实际正文高度，不能直接宣称 OriginOS 7 已达到同样数值。CSV 的余白测至字体安全框下缘；若按实际笔画像素验收，还要另测每行实际墨迹。低行距设置可能出现字体框相互重叠，数学合格不代表推荐使用。

## 2026-11-22：正常行距附近联合微调字号与段距

### 为什么联合微调有用，又有什么上限

理想模型令 T=H−G，取 n 个行间隙，将普通行进距 P 调到使 A=T−nP 接近半字预算 W。这样 S=A/n 时，全部段落分布的余白落在 [0,A]，可以同时消除大块固定底白并利用允许的波动预算。对指定正常行距区间 [Plo,Phi] 与贴底上限 B≤W，固定 n 的可行范围为：

```text
max(Plo, (T−B)/n) ≤ P ≤ min(Phi, T/n)
S = (T−nP)/n
```

优先选最小可行 n，可提高 S。无需先排全书；用字号、原生文字框、行距和正文高度即可搜索。不过任意段落排列的半字预算仍需覆盖同页所有潜在段界，因此 nS≤W，并不会因把倍率调细而消失。普通行距附近、字号约 39、每页约 10～15 行时，绝对段距仍主要是 1～2px 量级。允许每页行数变化，不等于任意段落分布都能靠变行数扩大这个通用上限。

原生测量沿用上一节本机字体及安全余量。字号 14～64 按 0.1 搜索，在扩展带探测每个整数目标行进距，并以实测行进距判定所属范围，共 9773 个原生 profile。每个整数标称字号保留 ±0.5 范围内的微调候选，分别按绝对额外段距最大、段距相对普通字体框空隙的增幅最大排序。15395 个贴底候选经筛选，得到 1464 条各窗口／范围／目标的优胜记录，见 [微调组合 CSV](evidence/reader-spacing-fine-combinations-2026-11-22.csv)。有些窄范围没有可认证候选，不虚构补齐记录。

该搜索不是全部实数参数域的精确全局最优证明；它是上述 0.1 字号网格、原生目标行进距、字体及包络内的候选最大值。原生布局会取整，不能只把理想倍率截成三位后认定结果不变。CSV 保留配置倍率的完整精度、实测行进距及安全上下界；表中倍率为近似展示值，实现时必须重新测量匹配，不能硬编码这些截图或本机数字。

## 2026-11-23：用户明确“行进距”为空白后的术语对齐

用户已明确：其所说的行进距是两行字形之间的空白，不包含字高。本节统一用F表示理想可见字高，L≥0表示行间空白，S≥0表示普通行距之外的额外段距，D=F+L表示相邻行字底／基线的总步进。L当然可以小于半字；此前P>W的P指D，不是L。对不重叠的理想等高模型，D≥F>F/2是由定义推出，不是对用户空白L另加限制。

GPT-6.2 Astra / ultra 子代理复核了一般D>0模型。若允许D≤F/2，旧简式确实不再必要。例如F=G40、W20、D20、S10、H760时，可达余白只有0/10/20，行数25..37；另有D=S10的73格分箱构造，可保留一位相位状态局部双向。但这些基线距离会让40高字形严重重叠，只证明旧定理不能无条件跨域，不是用户本次明确的‘空白行距’正常模型方案，不能据此声称正常阅读已得到通用解。

实际一页的准确公式为：

```text
R = H − kF − (k−1)L − qS
```

q为该页真实内部段界数，0≤q≤k−1。S只加q次；末行后不加行距或段距。不能将每张实际页都直接写成(k−1)S。

若另要求固定页顶、自然装入最大完整连续前缀，并对任意可能的段落排列都保证余白极差≤F/2，定义：

```text
n = floor((H−F)/(F+L))
A = H−F−n(F+L)
```

其通用充要判据仍是 `nS≤A` 且 `nS≤F/2`。qS是每页实际增高；nS是全无段界与每个间隙都跨段两类可达极端之间的最坏差。若nS≤A，所有普通页自然装n+1行，极差nS；若nS>A，存在两种排列因末间隙是否跨段而相差一行，余白相差整D>F/2。这个判据不是预设每页固定行数；对指定实际书籍不一定出现这些极端模式，不能作为每本书的必要条件。

联合选参时，令a=L/F、b=S/F、h=H/F，可直接计算：

```text
n = floor((h−1)/(1+a))
b_max = min(1/2, h−1−n(1+a)) / n     // n≥1
```

可遍历字号F和空白倍率a挑选允许的b，不需固定某个失败例子，也无需为此全书逐行排版。旧UI中的TextStyle.height参考1.2..2.4是总步进D/F的近似名义倍率；理想模型换成空白比例L/F应为0.2..1.4，原生实际步进还须测量，不能把1.2..2.4再当空白倍率重复加一个字高。

此次仅术语和数学复核，未改程序、构建、提交或推送。此前所有完整包、研究测试与验收事实保持原状。
