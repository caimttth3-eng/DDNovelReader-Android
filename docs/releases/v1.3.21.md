# 多多朗读 v1.3.21 · 段距切换与分页容量

版本为 **1.3.21（55）**。完整测试、Analyze、本地离线构建、固定签名、独立验签、SDK 全树审计、接收及收尾已完成；未安装真机，不以上一版结果替代本版验证。

## 修改

段距改为固定四档 **0、0.25、0.5、1 倍字号**，默认 **0.25**。已保存的合法 0、0.25 原样保留；旧 0.05、0.1，以及缺失、非法值迁移至 0.25。段距仍独立保存，随字号和系统文字缩放计算实际距离；不改行距、首行缩进或音色设置。

修正改变段距后再切回原档时，当前页和下一页切点受临时重排影响的问题。按完整布局身份保存最近四份数值切片，每份最多 385 个切点记录；恢复首个源文行后，在撤去重排遮罩前恢复匹配的数值末行和附近切片。缓存只保留游标、边界与豁免标记，不持有原生图片、TextPainter 或字体排版对象，也不做跨重启切片持久化。切换主题、旋转偏好等未改变实际几何的设置，不再无条件清空当前页末边界和页历史。

附近规划窗口按源章节固定，包含当前源章节及向前累计约 2 个正文屏高、向后累计约 3 个正文屏高的相邻章节；在同一源章节内移动，不再因当前行位置改变窗口端点。真实章节仍不是强制页界。新计划发布时，退休与其源范围重叠且尚未显示的旧建议，保留已提交切片，避免不同窗口的候选切点混用。临时窗口边缘仍需扩展后再显示，迟到结果继续按布局和导航代次丢弃。

生产规划改用 `solveReadable`。严格半字号余白区间方案只有在以下条件同时满足时才采用：与相同固定切点、强制边界下的最大完整行方案页数相同；每个普通非豁免页相较从该页起点可容纳的最多完整行，至多少一行。否则使用固定行距、固定段距下的最大完整行链，保留真实源文顺序和已提交约束，并报告实际余白范围。独立的严格 `solve` 数学接口保留，不能把它的可行性直接等同于适合阅读。

本版不再对任意固定段距、字体、入口或全书承诺半字号余白波动。某些正文结构只能通过大量增加页数、甚至一行一页满足该数值目标；此时优先保证页面容量，而不是把大块固定留白当成优化成果。实际 `bandStart`、`bandEnd` 和 `spread` 反映采用方案的真实范围，回退结果可能超过半字号。

## 数值研究依据

420 组纯数值组合覆盖字号 39、七档行高 1.2 至 2.4、五种固定段距 0.25/0.5/0.75/1/1.5 倍字号、三个正文高度及四种段落密度。其中 0.75、1.5 仅用于研究，不是新增菜单选项。几何不变，仅改变页尾选择；这些合成行表不代表 vivo 原生字体或真实书籍验收。

在行高 1.6 的研究组中，严格半字号方案最差页数相对最大完整行方案分别达到约 2.46 倍（段距 0.25）、6.05 倍（0.5）和 11.45 倍（1）。段距 1 的一组普通页仅一行、平均占用约 4.43%。这验证了严格波动达标与减少空白并非同一个目标，也是生产容量保护的依据。最终完整执行日志 `temp/spacing1321-tests-verified.log` 包含研究矩阵及容量策略验证；历史研究与本版取舍见 [阅读审查](../reader-layout-audit-2026-11-21.md)。
