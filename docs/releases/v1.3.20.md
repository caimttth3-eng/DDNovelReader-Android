## 修改

识别出的原文标题只加粗、居中，使用正文的字号、固定行高、颜色和普通段距；取消额外 6 号字号及上下各 16 像素留空。标题首行不占正文缩进宽度，但保留原文到显示的字符映射。正文和标题共同使用正常字重的固定 strut，避免粗体字体改变分配给一行的高度；标题变粗导致横向宽度变化时，仍按真实文字断行，不截断或缩小字号。

原文已有的标题只显示一次。真实 EPUB/章节元数据标题在原文没有时仍可显示，样式与原文标题一致。删除兜底分块的“第 N 节”“简介”“正文”等合成名称生成；技术分块保留原正文、边界及章节/原文坐标。目录无真实标题时使用定位点的原文短摘录，不再另生成分节编号。正文真实存在的“第 N 节”保留，标题分类不再凭这段字符串猜测并隐藏。

Git 历史中分块“第 N 节”语句来自最早可见提交 `22fcc52`（署名 Duoduo Developer），目录另一处生成语句来自 `c0fbee2`（署名 NayGnehz）。这两处都已在源头移除；前一版单纯显示隐藏方案已被取代。快照 schema 从 3 升至 4，旧快照不再复用，重新解析时不把旧合成标题带回；不修改真实书籍文件或同步原文结构。

物理章节不再是分页边界。附近章节组合成连续文字窗口，同一页可以包含前章结尾、下一章标题和正文；只有全书最后一页自然结束。计算窗口的两端未显示片段作为临时边界处理，不作为正式标题页或章尾页发布；接近边界时扩展文字再计算，避免人工窗口截断造成一行页或章末大片空白。已显示入口/切点、原文锚点、异步取消和过滤快照保护保留；滚动与重叠保留末行模式沿用原政策。

标题分类在阅读准备/快照读取的 worker 中缓存，界面重建不重复扫描全书。冷打开仍不等待全书排版，字体行表只准备当前附近窗口；精确半字号区间的保证限当前有效规划范围，不把有限窗口宣称为全书共同区间。
