# 多多朗读 v1.3.11 · 引擎选择与统一设置菜单

本修改版基于 [caimttth3-eng/DDNovelReader-Android](https://github.com/caimttth3-eng/DDNovelReader-Android)，来源与许可见 [来源说明](../SOURCES.md)。本轮仅本地修改和交付，源码保持未提交、未推送；未创建或更新 PR。

## 行为变化

- 本地语音按已安装 TTS 引擎名称选择，不把引擎上报的语言代码当作已验证可用音色；无法可靠确认有效性的内部条目不显示、不展开。“管理系统音色”保留，由用户进入系统或引擎设置详细配置。
- “仅显示优化音质”位于本地语音标题下方、全部引擎条目上方，默认开启。按各引擎**默认音色**的质量标记筛选，关闭显示全部；不因筛选切换当前引擎。没有匹配标记时提示关闭筛选查看全部。该标记来自引擎，不是应用对真实声音的测量；在系统设置修改后重新打开面板刷新目录。
- 沙漏圆点依据实际有效停顿是否偏离默认值；仅有默认值存储记录不再显示圆点，旧全局自定义停顿也会正确显示。
- “重置停顿”与“应用停顿”并排。重置弹出确认，确认后直接恢复并保存默认值、清除系统专属及旧全局覆盖，取消不改动。普通编辑仍需应用，关闭菜单放弃草稿；修改和重置不影响在线音源。
- 阅读设置、TTS 音源和朗读设置共用 85% 屏高、固定左对齐标题及 16 像素内容边距。条目左对齐、操作控件置于右侧；移除内容分隔线和展开边框，内容独立滚动。设置弹窗、菜单和确认框背景随主题，取消表面染色导致的偏绿底色。
