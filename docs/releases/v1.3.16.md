# 多多朗读 v1.3.16 · 页底完整行与过滤翻页事务

本次针对用户手机反馈继续复核 1.3.15 未覆盖的大字号与快速操作窗口。页尾及交互问题分别建立修复前证据，不以旧版全套通过替代本次复现。方案、官方来源与具体边界见 [设计审查](../reader-layout-audit-2026-11-21.md)。

## 变化与验证

- 页底按同行最大字体高度判断完整文字行，不再要求尾行的附加下半行距也必须放进正文区。页内实际行距、段间距、字号、32 逻辑像素页脚和允许行首标点保持原样。整行分页仍可能留下不足下一行进距的自然余量。
- 分页窗口、原文行定位、起读和朗读字形可见性共用这一高度规则；布局身份升为 typography5，旧像素定位沿用原文锚点恢复。
- 快速切过滤等级或开关时，在同一准备事务中采用最新草稿，过期结果不安装、不保存。安装前等待正在执行的翻页完成，捕获最终可见位置；无需新文本的切回原状态也保留期间最新位置。
- 恢复期间的手动翻页按顺序等待设置队列完成，旧页快照通过 IgnorePointer 让手势进入队列；朗读配置期间同样保留手动请求，避免取消已消费的过滤设置。自动跟随不反向等待，完成屏障均在 finally 释放。

新增 13 项回归：40/64 字号 × 长段/多短段的四项页底复现，以及九项快速操作、逐帧遮罩、稳定控制组、前后连翻、播放/暂停、切回原状态后的进度/起读。原有阅读、标题定位、起读与停顿阶段回归 106 项通过。

最终完整 Flutter 套件 **611 通过、8 可选探测跳过**；Analyze exit 0、无 error（198 warning/info）。新增测试沿用现有 Flutter material API，含该版本 API 弃用和字符串风格提示。源映射、音频分句和缓存格式未变，未升级固定工具或依赖。
