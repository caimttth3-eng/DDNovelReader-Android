# 多多朗读 v1.3.18 · 段落行距与长段打开性能

用户确认字号 39、默认行距和默认字体后，本次分别处理正文段落间的附加空白，以及最近版本打开书籍变慢的性能退化。两张手机截图不是连续页，不能据此推断翻页之间的原文衔接；图片也不能独立证明下一行在原坐标已经放得下。修复前反例、排版依据及调用计数见 [设计审查](../reader-layout-audit-2026-11-21.md)。

## 修改

- 开启首行缩进时，正文取消每段附加的 10+2 逻辑像素间隔，段内和跨段采用相同行进距；关闭缩进时保留块段落间隔。保留字号、用户行距、页脚和当前标点规则。布局身份升级，旧进度仍按原文位置恢复。
- 以实际排版身份和 RenderParagraph 缓存附近行范围，同一帧锚点与分页共享结果。普通重建、滚动和高亮不再重复测量整个长段；宽度、字号、字体、缩放、方向、正文及实际视口高度变化时重新测量。
- 远位置恢复和已记忆页面直接用目标字形定位附近窗口，向后准备段落使用尾部窗口；不拼接不连续的旧窗口。朗读和初始进度定位优先使用已有字形，无法取得时才创建独立 TextPainter。

原文锚点、过滤事务、已访问页历史、稳定整页图像和播放意图门控继续沿用。整行分页仍会保留不足下一行实际进距的自然余量，没有按页拉伸行距。
