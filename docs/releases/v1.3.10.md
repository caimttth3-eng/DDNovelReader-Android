# 多多朗读 v1.3.10 · 系统引擎选择与音源面板

本修改版基于 [caimttth3-eng/DDNovelReader-Android](https://github.com/caimttth3-eng/DDNovelReader-Android)，由 NayGnehz 在其基础上维护，非原作者官方发布。延续已合入的上游 `514661efc702365afd313fbd7600c39adda35624`，来源与许可见 [来源说明](../SOURCES.md)。

## 行为变化

- “本地语音（系统 TTS）”直接列出已安装的引擎和音色；点击即切换对应引擎及音色，按书保存，兼容旧的系统音色记录。同名音色保留各自引擎身份。
- 使用具体已选音色名，移除“系统语音（离线）”及说明。不再隐藏普通音质、其他语言或需联网的音色；需要网络的具体音色有相应标注。引擎不报告音色时保留其默认入口，仍可打开系统语音设置。
- 原生枚举使用独立 TTS 实例，不切换播放引擎；合并并发请求、限制探测数量和等待时间，退出时释放实例。在线音色在枚举期间仍可选择。
- 系统沙漏新增“重置停顿”，先恢复默认草稿，点击“应用停顿”才保存；清除系统专属及旧全局覆盖。默认破折号、省略号各 0.20 秒，段后 0.30 秒，其余 0。自定义和重置均只影响系统音源；在线断句、请求及缓存参数不变。
- 在线语言分组仅默认展开当前已选在线音色所在组；选择系统音色时全部默认收起。每组可手动展开或收起，原生枚举完成不会覆盖手动状态；自动系统兜底时保留原在线选择所在组。
