# 多多朗读 v1.3.12 · 菜单层级与本地音源短名

本修改版基于 [caimttth3-eng/DDNovelReader-Android](https://github.com/caimttth3-eng/DDNovelReader-Android)，来源及许可见 [来源说明](../SOURCES.md)。本轮仅本地修改和 APK 交付；未暂存、提交、推送或操作 PR，HEAD 保持 `4dc2d62286430ddc7e66cc3816e788757971e22f`。

## 行为变化

- 设置菜单主标题统一为 20，分组标题为主题重点色 16/半粗体，普通文字 16，辅助说明 14。恢复清楚的主次层级，标题及主要分组边界使用轻分隔线，普通条目不逐行分隔。阅读设置、TTS 和朗读设置沿用共同的 85% 屏高、左对齐及内容边距。
- 浅色弹出菜单恢复白底；深色为中性深灰，取消表面染色。阅读纸张颜色保持自身主题，切换主题的文字样式动画兼容。
- “仅显示优化音质”保存到全局设置，重新打开菜单、重新进入阅读页或重启后保留选择。仍按引擎默认音色质量标记筛选；不因筛选改变当前引擎。
- 阅读控制栏的本地音源按钮提取引擎关键词，例如“iOS-婷婷”显示“婷婷”、“AiService TTS”显示“AiService”，并增加显示宽度。无需先打开音源菜单即可显示；完整名称保留在提示中。名称预取只读已安装引擎元数据，不初始化音色探测或改变播放路由。
- 页面退出及时取消目录等待，忽略迟到回调，避免未响应的名称请求留下 15 秒计时器或触发后续初始化。
