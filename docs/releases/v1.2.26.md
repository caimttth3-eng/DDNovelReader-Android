# 多多朗读 v1.2.26 · 阅读与朗读增强版

本修改版 fork 自 **caimttth3-eng** 的 **[DDNovelReader-Android](https://github.com/caimttth3-eng/DDNovelReader-Android)**。原始 Flutter 应用、基础阅读和 Edge TTS 集成来自原作者，本仓库由 **NayGnehz** 维护后续阅读与朗读增强，非原作者官方发布。来源及第三方许可见 [SOURCES.md](https://github.com/NayGnehz/DDNovelReader-Android/blob/master/docs/SOURCES.md)。

## 相对上一公开 Release v1.2.23 的更新

- 优化在线语音预加载：命中缓存时不再每句闪现加载提示，移除无谓等待及满窗轮询；完整音频及时交付，异常断流不缓存为完整语音。
- 自定义追加停顿仅保留在系统音色旁，沙漏入口直接展开；单个“应用停顿”按钮保存，关闭丢弃未应用草稿。保留旧系统设置，在线音色不再采用历史自定义停顿。
- 修复系统朗读连续跨章时沿用上一章词位置、导致短章节标题只读末字的问题；保留有效词位置续读，并修复短行视口定位边界。
- 通知原文长句随真实朗读进度显示短片段，优先在可用标点处截断；无合适标点的过长部分再截断，隐藏段首缩进。无真实范围信息时保持整句显示。

## 下载与安装

- 仅 **ARM64-v8a**，Android 7.0（API 24）及以上，APK 约 **19.4 MB**。
- 沿用固定签名，可覆盖安装使用相同证书的近期版本。与原版或早期临时签名不同，切换前应备份书籍与数据。
- 附 APK 和对应 `.apk.sha256` 文件；未打包其他项目的语音引擎或声库。
