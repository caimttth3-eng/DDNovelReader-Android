# 多多朗读 v1.3.14 · 系统语言与起读定位修复

本修改版基于 [原 Android 项目](https://github.com/caimttth3-eng/DDNovelReader-Android)，来源及许可见 [来源说明](../SOURCES.md)。本轮仅本地修改及 APK 交付；没有暂存、提交、推送或操作 PR，HEAD 保持 `4dc2d62286430ddc7e66cc3816e788757971e22f`。

## 行为变化

- 播放菜单四个按钮恢复等宽等距，同级字号一致。本地引擎关键词较长时允许两行，完整名称提示保留。
- “朗读音源 → 本地语音”中，引擎右侧新增“选择语言”。用户点击后才调用该引擎的 `ACTION_CHECK_TTS_DATA`，仅成功返回的有效安装清单可以选择；失败、空结果、取消、无 Activity、配置脱离及超时均安全结束，不回退到 `getVoices` 的泛化音色表。选择按书保存，以明确语言调用 `setLanguage` 并检查支持状态，可恢复“跟随系统设置”；管理入口及音质筛选记忆保留。
- Android 旧固定音色记录在播放出口兼容为同引擎默认音色；旧记录没有引擎身份时使用系统默认引擎。新明确语言记录保留语言，原存储、停顿及缓存身份不改写，iOS 显式音色保持。
- 含普通点分网址的页面直接开始朗读时，分页与起读共用同一次完整页首行坐标，避免把上一行残余行距盒当起点而退回一页。滚动模式继续允许当前可见半行。另独立修正重复符号清洗后的字符起点/逆映射；普通网址问题不归因为不存在的双斜线。
- 系统通知原文先按每个标点切分，只有一两个字的逗号段也独立显示；仅单个长段使用原宽度窗口。起读、换句和句中续读先确定真实位置再发布，缺少词范围显示首段，避免先闪整句或下一段再撤回。不改变真实 TTS 分句、音频或缓存。

Android 设置页采用安装数据检查与旧 `getVoices` 路径不同，参考 [AOSP 设置页](https://android.googlesource.com/platform/packages/apps/Settings/+/master/src/com/android/settings/tts/TextToSpeechSettings.java) 和 [官方安装检查契约](https://developer.android.com/reference/android/speech/tts/TextToSpeech.Engine#ACTION_CHECK_TTS_DATA)。用户报告 vivo OriginOS 7 的 AiService 有中英、婷婷仅中文；本轮未在该手机上获取实际返回值，不保证检查恰好返回两项。选择英语不会翻译或在应用端过滤中文，实际跨语言处理由引擎决定。
