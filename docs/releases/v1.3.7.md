# 多多朗读 v1.3.7 · 本地构建发布

本修改版基于 **caimttth3-eng** 的 **[DDNovelReader-Android 原项目](https://github.com/caimttth3-eng/DDNovelReader-Android)**，由 **NayGnehz** 维护后续阅读与朗读改进，不是原作者官方发布。Flutter 基础应用、阅读及 Edge TTS、WebDAV/跨端功能来自原项目；来源和第三方许可见 [SOURCES.md](https://github.com/NayGnehz/DDNovelReader-Android/blob/master/docs/SOURCES.md)。

## 本次公开更新

- 合入原作者 1.3 的 WebDAV、多编码文本及跨端缓存能力，修复严格 WebDAV 服务首次同步的远端根目录创建问题；通过统一映射兼容原始断行/缩进、显示位置与规范化码点坐标。
- 朗读按完整视觉页跟随，自动翻页不切断同一句音频；手动翻页从目标页首字符起读，忽略旧语音定位回调。高亮不绘制到被裁切的隐藏行。
- 普通阅读和朗读共用实际行边界，修复页底半行、双向分页卡住及中间定位画面闪现。新页完成裁切后才显示。
- 主页可保存深浅主题及书架/列表选择；同步、关于、缓存管理等界面和返回主页的状态栏适配主题。
- 网络失败转系统音源改为可选，默认关闭；语速继续按 0.02 调整并保存两位小数。完整变化见 [CHANGELOG.md](https://github.com/NayGnehz/DDNovelReader-Android/blob/master/CHANGELOG.md)。
