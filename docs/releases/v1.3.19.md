# 多多朗读 v1.3.19 · 固定段距与整章联合分页

## 修改与范围

阅读设置在行距下方新增 0、0.05、0.1、0.25 四档额外段距，单位是字号倍数，默认 0.1。设置独立保存；旧配置没有该项时迁移为 0.1。首行缩进不改变段距。实际额外段距为系统文字缩放后的字号乘所选比例，普通行距继续由原行距设置决定，两项在同一设置下均固定，不逐页拉伸。

段距只在同章相邻有效正文段之间加一次；章首第一段不加，段末不加尾距。页占用以最后完整文字行底部减去第一完整文字行顶部计算，不要求页末再容纳行距或下一段的间隔。

完整原始 TextSpan 仍承担横向排版、命中、高亮及原文映射，不把页子串重新断行。新行表服务按实际字体、方向、缩放、宽度和缩进测量字形范围；字体测量在 UI isolate 分批让出，纯数值页尾规划通过 compute 在后台执行。首次打开不等待整章行表，第一次规划翻页才测量当前章，随后复用；单个原生长段 layout 仍不可中断，不能把此方案说成没有额外首次翻页成本。

整章页尾共用一个半字号宽的余白区间，先求最少页数，同页数再优先较小的最大余白。明确固定已显示页面的首末切点及其豁免身份；普通规划页不能在重算时偷偷改为豁免。章首标题页、章尾及已经显示的入口页不约束余白极差，避免为完整章尾或保留原文位置造成不必要的空页。向前、向后均在完整章行表上规划，不再分别挑选独立的前缀或后缀区间。

改变字号、行距、段距、字体、缩放、视口或过滤会使对应计划失效并保留原文位置。目录、搜索、同步进度等直接导航退休旧请求；迟到 worker 不能改动当前入口页。已计算的建议切片只在实际翻页时启用。上下滚动与保留上一页末行的重叠模式继续沿用既有行为；跨章节、任意重新定位不承诺全书共用同一区间。特殊字形高度或已固定切点不容许求解时，继续完整行分页，既不改间距也不删行。

较大段距可增加总页数及固定留白，半字极差不等于每页尽量铺满。数学依据、合成代价表与成熟实现对照见 [阅读审查](../reader-layout-audit-2026-11-21.md)。测试目录的旧研究算法已改为生产规划器薄适配，避免保留两套候选搜索和 DP。
