# 1.3.24（58）固定段距与连续分页

日期：2026-11-23。本轮仅本地修改、验证和签名 APK 交付；未安装、暂存、提交、推送、操作 PR 或发布远端 Release。

## 行为

段距默认无额外间隔；其余三档为实际字号的¼、½、¾。同一字号下段距固定，不按页内段数调整；修改字号或系统文字缩放按实际显示字号重新计算。行距保留用户选择，不再自动调整字号和行高。

旧模型设置没有 `paragraphSpacingModel: 'fixed'` 标记时首次迁移为0，避免把原来很小的二档突然放大为半个字号。新版本写入模型标记，用户后续选择的0～3档按原有全局／分书设置保存。

取消半字余白硬约束和固定K行。正向从当前页界装入最大完整连续前缀，反向装入当前页界之前的最大完整连续后缀。已访问页保留精确首末端点；技术章节和临时测量窗口不能形成普通短页，真正的书首／书尾剩余不足一页时允许自然留白。标题仍同正文的字号、行高和段距，仅加粗居中，跨章连续。

页底余白自然小于下一完整行的真实推进量；段内通常为P，跨段通常为P+S，混排按实际行框坐标计算。此处不承诺严格小于普通行距P或半字号，也不以加空行、拉伸间距或隐藏能放下的完整行实现。

连续翻页手势在已显示快照外接收，翻页过程中按顺序排队；正文工作布局仍隔绝点击和隐藏中间帧，避免部分反向点击丢失后停在错误页。数值窗口仅缓存本次请求方向的候选，不把反向后缀当成新前向前缀。已显示页优先，候选和已显示切片均沿用有界历史容量。
