# 阅读与播放设置

设置保存在应用全局，重新启动或换书后沿用。

阅读设置依次分为外观、翻页、屏幕、文本处理四组。亮度与字号使用阅读菜单中的快捷入口，阅读设置内不再重复显示。

- 语速按钮与滑杆都按 0.1 调整，界面显示一位小数；旧设置按最近的 0.1 恢复。
- 翻页动画默认为关闭，可选择平移；上下滚动仍使用滚动模式。
- 左右翻页时收起浮动控制栏；正文区域不随控制栏显隐改变大小。目录远跳后上一章尚未排版时先准备上一段，再按文字行定位，并复核同一目标行的实际页首坐标。
- 默认竖屏锁定，通过现有横竖屏按钮切换；开启“跟随系统旋转”后才跟随设备和系统设置。
- “播放设置”位于音源右侧，包含在线预加载、逐词高亮、朗读时亮屏时长及拖动触发延时。
- “在系统栏中显示播送原文”默认关闭；开启后，标准媒体卡片随句显示当前朗读原文。关闭或停止后清除该原文，书名与章节保留。
- 阅读设置中的“阅读亮屏时长”独立保存，默认跟随系统，可选 1分钟、2分钟、5分钟、10分钟、30分钟。按用户确认移除秒级选项。
- 朗读时亮屏时长默认跟随系统锁屏，提供 15、30、60、90 分钟及自定义 1–120 分钟；到期恢复系统自动锁屏，不强制锁屏。
- 阅读与朗读分别使用各自的无操作计时，切换模式重新起算；暂停朗读时恢复系统锁屏，进入后台立即释放亮屏覆盖。
- 使用与开源阅读器 Legado 相同类别的保持常亮/到期释放机制，不新增辅助功能或设备管理器授权，不修改手机系统锁屏设置；到期后实际熄屏仍由系统决定，不承诺跨系统的精确强制锁屏。
- 拖动触发延时默认 0.2 秒，可选择 0–0.5 秒，步长 0.1 秒。

## 个性化停顿

追加停顿入口只保留在音色选择菜单的“系统”音色旁，使用沙漏图标；播放设置和所有在线音色不再显示此入口。设置仅作用于系统音色，包括断网后自动回退的系统音源。旧系统专属配置优先沿用；没有专属值时兼容旧版保存的停顿。历史在线配置保留在数据中，但不参与播放或缓存分句。

点击系统音色旁的沙漏直接展开追加停顿，顶部不再显示重复的“系统的追加停顿”大标题；“追加停顿”右侧显示单个“应用停顿”按钮，修改后点亮。关闭菜单放弃未应用的草稿。每个音色的语音缓存仍按对应的有效分句与指纹读取；在线音色使用固定默认停顿，不提供自定义入口。

在音源的自然停顿基础上追加。新用户或未保存对应项时，默认破折号和省略号各 0.20 秒、段落 0.30 秒，其余类别追加 0.00 秒；已有设置中的明确数值保持不变。
可分别调整顿号、逗号、分号、冒号、句号、问号、叹号、省略号、破折号和段落，范围 0.00–3.00 秒，步长 0.05 秒。内部仍使用毫秒保存，与已有设置兼容。
点击“追加停顿”展开或收起各项。每项在同一行显示“标点符号＋秒数＋短滑杆”，仅段落项使用“段后”文字；符号与两位小数秒数使用固定列宽，滑杆不会随数值长度改变位置，点击数值也可输入秒数。修改先保留在菜单草稿中，点击标题右侧的“应用停顿”才保存；当前有效停顿变化时一次性在后台准备新分句。直接关闭停顿菜单不保存草稿，仅收起追加停顿区域也不触发应用。暂停时应用后仍保持暂停，再次播放从保存的词位置继续。
邻接标点及段落边界取最大追加值，避免同一位置叠加多次；不会改写原始书籍。

参考 [W3C SSML break](https://www.w3.org/TR/speech-synthesis11/#S3.2.3) 与
[Microsoft SSML silence](https://learn.microsoft.com/en-us/azure/cognitive-services/speech-service/speech-synthesis-markup-structure)。
这些资料区分自然停顿、追加停顿及精确停顿，没有给所有引擎统一的自然停顿毫秒数。
微软还说明逐词边界事件可能优先于精确标点停顿设置；本应用因此在播放调度中执行追加停顿，
系统音源使用已保存的自定义配置，在线音源使用固定默认值，不依赖在线端接受额外 SSML。
