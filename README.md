## 主要功能与修改

### 阅读、排版与目录

- 主页右上角可切换深色／浅色和书架／列表，两项选择均会保存。列表保留原版的文件图标、格式、一位小数进度及长按删除。数据同步、关于和缓存管理等页面随应用主题切换。

- 保留 TXT / EPUB 导入、书架、查找、书签、划线和自选字体；逐书保存进度，重新进入继续阅读。
- 普通阅读提供“点击左右侧 / 左右滑动 / 上下滚动”三种方式，默认上下滚动，可在阅读设置调整；已有显式选择保留。点击/滑动分页以完整文字行为边界，可选择保留上一页末行。
- 页尾按同一视觉行各字体片段的原生安全范围并集判断完整容纳，末行后不计行距或段距。字号、行距沿用用户选择，不再按页高自动调整。行距下提供无额外段距、¼ 字号、½ 字号、¾ 字号四档，默认无；同一字号下段距固定，不按页内段落数拉伸，与首行缩进独立。升级时未带 `paragraphSpacingModel: 'fixed'` 标记的旧段距设置统一迁移为无，避免旧近零档位变成明显大间隔；新模型中的选择会持续保存。
- 普通分页与朗读分页从当前边界双向取最大完整连续前缀或后缀，每页行数由真实文字和段界决定，跨章继续填充，不为缩小余白主动少排一行。历史保留已访问页的精确首末原文位置，避免返回时产生短残页；到达真实书首或书尾而剩余内容不足整页时，可自然留白。装满页余白自然小于下一完整行所需的实际增量；跨段时该增量包含额外段距，不能一概承诺小于普通行进距。标题同字号和行高、仅加粗居中。已访问页最多记忆256页，自由滚动不作固定页底约束；原生安全框不等同墨迹像素边缘，测量范围见阅读审查。
- 翻页动画可关闭或使用平移，默认关闭；上下工具栏覆盖正文，显隐不挤占正文空间。
- 过滤恢复和翻页使用带纸张底色的不透明整页快照，平移期间绘制稳定前后页，结束后恢复实时正文，避免隐藏的新正文透出旧快照。暂停后翻页再播放会等待语音定位完成，等待期间再次暂停可撤销恢复。
- 两端对齐、允许行首标点、字号最大 64；亮度和字号快捷滑杆提供 48 像素触摸高度，字号释放后统一重排并保存。亮度 A 等待恢复系统控制后刷新滑杆，再作一次延后刷新，旧读数及排队设置草稿不能覆盖新调节；滑杆左侧仍可额外调暗。
- 自动提取 TXT 目录与章节标题，默认开启；无真实标题或关闭识别时，按约 5000 字间隔的原文短摘录定位。技术切块不再生成“第 N 节”等标签，原文真实标题保留；旧快照失效后重解析。支持目录跳转和进度拖动。
- 文本修正、首行缩进默认开启，同时作用于显示和朗读；分级无关内容过滤默认开启一级，可关闭。通过原文坐标映射保持进度、书签和高亮位置。
- 深浅主题默认跟随系统；适配刘海和挖孔区域的章节信息，默认竖屏锁定，可手动横竖屏切换或开启跟随系统旋转。
- 自动翻页支持间隔选择、移动指示线及暂停/停止。

### 朗读与播放设置

- 支持原有 Edge 在线音色及系统文本转语音。在线音色按简繁中文、英语、日语和韩语分组，仅默认展开所选音色所在组，每组均可手动展开或收起；选择系统音色时在线组全部默认收起。在线音色、本地引擎和语言选项的选择圆点统一在文字左侧。本地语音按已安装引擎的名称切换；Android 引擎右侧“选择语言”仅在用户点击后检查该引擎安装的语言，成功返回的条目可手动选择，也可恢复“跟随系统”。“管理系统音色”移至本地语音标题右侧的齿轮；语言与停顿图标紧凑并排，中心间距 40 像素。
- 进入阅读页即后台读取本地引擎名称，无须先打开设置。朗读栏只显示短名，例如 `iOS-婷婷` 显示为“婷婷”、`AiService TTS` 显示为“AiService”，不附加“音源”前缀；提示及设置列表保留完整名称。播放菜单四个功能按钮等宽、等距，同行字号一致，本地短名较长时允许两行显示。
- Android 播放旧版系统音色记录时只沿用引擎，去掉隐藏的固定音色／语言绑定；无引擎身份的旧记录按系统默认处理，存储和停顿记录保持原样。系统语言能力以引擎实际行为为准：用户反馈 AiService 支持中英、婷婷仅中文；中文正文仍读中文不能单独证明英语选择失效，应用不做语言过滤或正文翻译。
- 显式语言选择由 `ACTION_CHECK_TTS_DATA` 的成功安装清单提供，不采用引擎笼统上报的全部 `getVoices` 语言；检查失败、取消或超时不回退到该列表。语言选择按书保存，重新打开菜单继续显示已选项；播放时通过 `setLanguage` 检查引擎是否接受。真实 vivo OriginOS 7 尚未实测，不能保证返回清单数量或每项的实际输出。
- “仅显示优化音质”位于本地语音标题下、全部引擎条目上方，按各引擎默认音色的质量标记筛选引擎，关闭后显示全部，筛选不改变当前选择。开关会记住用户选择，重新打开菜单、切换书籍或重启后保留；旧配置没有该项时默认开启，明确关闭值不会被覆盖。离线能力、实际支持语言及词范围回调取决于引擎，不把上报的语言列表视为实际朗读能力的证明。
- 阅读设置、TTS 音源和朗读设置统一使用 85% 屏高、左对齐固定标题和 16 像素内容边距，内容区域滚动。主标题 20、半粗，分组标题 16、半粗并使用主题重点色，设置文字 16、说明文字 14，同层级对齐及间距一致，只在分组边界使用轻分隔线；浅色弹出菜单为白底、深色为中性 `#1A1A1A`，不随羊皮纸等阅读底色改变，也不附加偏绿的表面染色。
- 整句高亮；可开启逐词高亮，缺少真实词边界时自动回退整句。使用实际范围与时间信息，不估算逐词时间。
- 前台朗读只整页翻页，跨页同一句连续播放，不为翻页切断音频。有实际词位置时按页界翻页；没有词位置时到下一句再定位。在点击或滑动分页模式中直接开始朗读，页首选择与分页使用同一套完整文字行规则，避免上一行残留的行距盒被误选为起点、画面退回前页；上下滚动模式继续沿用原半行可见判定。重复符号清理另使用精确字符起点和反向映射，修复被合并符号后的字符偏移。
- 切换无关信息过滤及其他文本设置时，保留原文位置映射；分页捕获、起读与恢复共用文字行坐标和边界公差。快速修改等级或开关会合并到最新草稿，安装文本前等待当前翻页完成，再保留普通阅读期间最新的翻页或自由滚动位置；即使最终恢复原过滤状态、无须安装新文本，也更新到最新可见位置。恢复时保留旧页遮罩，期间的手动翻页按顺序等待恢复完成，朗读配置期间的翻页也沿用这一保护。配置期间新发出的暂停取消自动恢复，播放请求延后至新朗读队列就绪。设计与验证范围见 [审查记录](docs/reader-layout-audit-2026-11-21.md)。
- 朗读时上下滑动切句；按下后上下拖动可连续切句，触发延时默认 0.2 秒，可调整。
- 音量键正常调整媒体音量，并同步播放栏；语速按钮和滑杆按 0.02 调整，显示并保存两位小数。在线音源为 0.50–2.00 倍，Android 系统音源为 0.50–3.00 倍；2026-11-20 晓晓与云希固定短文实测请求 3 倍与 2 倍时长相同，因此保留在线 2 倍上限。切换音源时超出上限的值同步收紧。音色和语速按书保存，首次打开的书沿用全局设置。
- 在线预加载默认后续 8 句，可设置 0–100 句；同一个窗口可以跨越章节和空章，共用并发、缓存坐标、词边界及取消机制，不再额外固定预取下一章 3 句，设为 0 则完全关闭自动预加载。每个在线音色旁提供全书缓存入口，缓存按目标音色限制语速，不改变当前系统音源的速度。网络失败先用已有音频；“网络失败时转系统音源”默认关闭，开启后缓存用完自动切换，恢复联网后由用户手动切回。关闭时有限重试后提示错误，不悄悄换音源。
- 系统引擎旁的沙漏提供追加停顿，点击后直接展开；可按标点和“段后”调整，仅作用于系统语音。破折号、省略号默认各 0.20 秒，段后默认 0.30 秒，其余 0。范围 0.00–3.00 秒、步长 0.05 秒；普通修改点击“应用停顿”保存，旁边的“重置停顿”经确认后直接恢复并保存默认值，取消不变。沙漏圆点只表示有效数值偏离默认值，修改和重置不改变在线音色的断句、请求及缓存参数。
- 系统通知栏和锁屏支持上一句、暂停/继续、下一句、停止；可开启“在系统栏中显示播送原文”，默认关闭。每个标点段独立显示，一两字的逗号段也不与下一段合并；仅单个长段按真实词位置切换显示窗口。缺少词范围时保持首段，起读时使用实际初始位置，避免先闪整句再跳回当前段。通知隐藏段首缩进，不改变真实 TTS 分句、音频或缓存；最终样式和可见行数由手机系统决定。
- 缓存面板先显示再扫描，可重新核对磁盘音频和进度；取消/暂停等待在途写入结清，扫描失败不清空旧进度。仅按已知书籍 ID 及正文分区迁移兼容缓存，不按同名书直接复用。缓存管理可手动导出脱敏诊断，支持取消，不在启动时自动导出。
- 系统音频中断与手动操作共用暂停和续读路径，同步页面、媒体通知及亮屏状态；仅恢复确实因中断暂停的朗读，手动暂停、跳读、停止或离开阅读页后，不由旧恢复事件重新播放。能否收到中断和恢复事件由系统音频会话决定，尚未进行真机中断验收。
- 定时停止支持自定义，最长 120 分钟；阅读和朗读亮屏时长分别保存。亮屏到期释放窗口常亮，由系统处理熄屏，不申请设备管理器或辅助功能权限。

修复包括远距离跳转后空白、选章后上一页首行裁切、音源切换后高亮停滞、暂停后从段首重播、变速后位置匹配及通知暂停后无法继续等路径。两个偶发报告（念出标点名称、倍速后中央点击改变光标）的相关风险路径已有回归测试，尚未在真机完整复现其所有触发方式。

### 上游 1.3 新增能力

- 本轮适配1.3.4：同步页保留“双向同步”，新增“保存到云端／从云端读取”，阅读页四等宽槽中的同步菜单也提供三种模式。先显示预计差异并确认，书源补传及仅保存删除信息也会计入；同步预览本身不改书籍数据或远端。执行前绑定确认的服务器配置，重新检查数据，不凭同步点击制造新进度时间。上传不接受远端数据，下载不写远端；自动同步仍为双向。
- 记录上传按同次GET正文的强ETag进行条件写，每轮412都重新合并并继续条件写，创建用If-None-Match，最多4次尝试。服务器不提供有效强ETag时仍可下载，需要覆盖的上传会明确失败。逻辑删除继续同步，远端书源和旧别名保留，不自动执行缺少多资源事务保护的物理清理；旧别名仍参与归并，书签删除版本及未知百分比保护继续保留。协议、边界和优劣见整合说明。
- WebDAV 与桌面端同步书架、阅读进度、书签、书籍原文件和删除记录；音频不上传。配置后默认启动及每10分钟自动同步，也可在书架设置关闭自动同步，阅读菜单可手动同步。首次配置前请了解书源上传及删除传播范围。
- 同步接受新进度时暂停并跳转，接受书籍删除时关闭对应阅读页。同内容重复条目归并进度、标注及最近打开引用，保留全部源文件。书签按 ID 合并并附带兼容的删除版本；旧桌面客户端可能忽略删除字段，不能保证它执行书签删除。修复与验收逐项记录见 [24 项整合问题台账](docs/integration-repairs-2026-11-20.md)。
- TXT 支持 UTF-8 / UTF-16 / GBK / GB18030 / Big5 识别；采用跨端内容指纹、整数语速目录和原文码点坐标，同时保留本项目原始断行/缩进及处理开关。新 `words2` 指纹隔离旧坐标音频，迁移冲突保留旧文件而非覆盖/删除。
- iOS 工程和上游说明随源码保留，当前只验收 Android ARM64；未进行 iOS 编译、签名或设备验收，iOS 在线 workflow 同样停用。

## 构建与验证

开发、测试及发布包均改为本地构建，不再使用 GitHub Actions；[旧在线构建配方](.github/workflows/build-apk.yml) 和 [固定 v1.2.26 发布配方](.github/workflows/publish-release.yml) 均无 push、PR、手动触发并固定跳过 job。Release 直接上传本地已验签成品。历史运行和验证记录不改写，也不因环境缺项回退在线或全局工具。

固定输入为 Flutter 3.50.0（官方 Windows 包随附 Dart 3.14.0，满足项目 `^3.13.2`）、Gradle 9.3.1-all、AGP 9.1.1、Kotlin 2.4.0；依赖以 `pubspec.lock` 为准。共享维护者登记并接收不可变工具/离线闭包，项目在 `ddnovelreader/main` 实例的 Prepare 锁下恢复可写 Flutter 运行树和缓存，不在共享 SDK 的 `bin/cache` 执行写入。Android 使用精确 API 36、NDK 28.2.13676358，不用现有 API 37 冒充。

官方 SDK 的最小锁兼容调整仅为 listen 1.0.1、test_api 0.7.14、vector_math 2.4.4；本次合并沿用该冻结包集、镜像和锁字节。上游直接使用的 audio_session 0.2.4 已在闭包中，现于 pubspec 明确声明；`--enforce-lockfile` 保留原锁中展示性的传递依赖分类，实际依赖图已验证其为直接依赖，不新增/升级包。`PUB_HOSTED_URL` 固定为 `https://pub.flutter-io.cn`，不换源重解或执行 `pub upgrade`。

项目入口（默认离线，固定闭包由共享维护者接收；命令存在不等于某次产品构建已经通过）：

```powershell
.\scripts\LocalBuild.ps1 -Action Prepare -IncludeAndroid
.\scripts\LocalBuild.ps1 -Action Restore
.\scripts\LocalBuild.ps1 -Action Analyze
.\scripts\LocalBuild.ps1 -Action Test
.\scripts\LocalBuild.ps1 -Action BuildApk -ConfigureOnly
# 需要实际未签名 ARM64 APK 时再执行：
.\scripts\LocalBuild.ps1 -Action BuildApk
# 完整本地交付（既有固定签名持续授权，不安装或远端发布）：
.\scripts\LocalBuild.ps1 -Action DeliverApk
.\scripts\LocalBuild.ps1 -Action Finalize
```

`Test` 默认覆盖本轮朗读分页、手动翻页定位及 TTS 队列回归，可通过 `-TestPaths` 指定现有测试文件。入口默认离线，先执行离线恢复。当前闭包由共享维护者接收种子，项目不并行联网接收同一份依赖；只有明确交接接收职责后，才可在确缺依赖时显式使用 `Restore -Online` 接收锁定 pub 依赖，或 `Prepare -Online` 接收宿主 engine/font。联网准备仍持有本项目 Prepare 锁，不升级依赖或读取凭据。

`BuildApk` 通过共享 `Tool gradle-9.3.1` 直接只读使用精确 Gradle 9.3.1 分发执行 `assembleRelease --offline --no-daemon`，不依赖缺失的项目 wrapper，也不回退 Gradle 9.7.0。Android SDK 直接使用共享 `Environment` 的固定路径，包含 API 35/36、NDK 28.2.13676358、CMake 3.22.1、Build Tools 36.0.0、Platform Tools 37.0.1 和许可；不自动调用 sdkmanager，不向实例重复恢复 Gradle/SDK。`GRADLE_USER_HOME`、`ANDROID_USER_HOME`、pub/Maven、TEMP 和构建输出仍留本实例；Flutter 的缓存及 Gradle 插件状态固定写入 SDK，因此保留实例可写树，不改上游或加联接。共享闭包仅验收 ARM64 release，不冒称 debug/profile 全闭包。默认清空签名配置，只接受明确未签名、版本匹配、仅 ARM64 且包含 Flutter/应用库的 staging APK，并保存实际校验信息；`-ConfigureOnly` 仅验证任务图，不生成 APK。

共享维护者已正式接收四份 `package.xml`，并核证固定 Repository 对只读缓存写入失败的兼容性。入口在 Prepare lease 内验证这些元数据，以只读共享句柄保护既有 16B `.knownPackages`；缺失或无法保护即停止。句柄持有至进程后代自然结束、日志消费和完整 SDK 树后验完成，不忽略任何元数据差异，也不改 ACL/属性/联接。`DeliverApk` 将构建、固定签名和 LocalApk 接收放在同一护栏生命周期。精确结果见 [本地布局](docs/local-layout.md)。
